# G0 色彩令牌

> 适用：P-01、S-01、G-01、T-01、A-01 及其后续同语言页面。数值来自已批准的视觉基线；开发不得从效果图取色。

| Token | 值 | 用途 |
| --- | --- | --- |
| `COLOR_PRIMARY` | `#1764D8` | 主按钮、当前导航、关键链接与进度 |
| `COLOR_PRIMARY_PRESSED` | `#0C4FB8` | 主按钮按下 |
| `COLOR_TEXT_PRIMARY` | `#071E49` | 标题、正文、关键数字 |
| `COLOR_TEXT_SECONDARY` | `#596987` | 辅助信息、未选中导航 |
| `COLOR_SUCCESS` | `#1FA968` | 完成、通过、有效结果 |
| `COLOR_WARNING` | `#F3B91C` | 提醒、点读、高亮 |
| `COLOR_URGENT` | `#E45A22` | 截止、逾期、未完成 |
| `COLOR_AI` | `#6542CE` | AI、录音、创意学习能力 |
| `COLOR_SURFACE` | `#FFF9F0` | 暖白内容卡与大面积表面 |
| `COLOR_PAGE_NEUTRAL` | `#F6F8FC` | 教师、家长及后台的克制底色 |
| `COLOR_SKY` | `#76CBEF` | 学生/公共端顶部天空与轻背景 |
| `COLOR_NATURE_DEEP` | `#3FAF57` | 外缘树叶、草地深层 |
| `COLOR_NATURE_LIGHT` | `#69C95A` | 外缘树叶、草地浅层 |
| `COLOR_BORDER` | `#D9E3F5` | 输入框、弱分隔线 |
| `COLOR_DANGER` | `#D9342B` | 错误与危险操作；不得以橙色替代 |

文本、按钮和状态文字以 WCAG AA 为最低目标。渐变仅可用于主按钮与学生/公共端天空层，不能代替状态色。
