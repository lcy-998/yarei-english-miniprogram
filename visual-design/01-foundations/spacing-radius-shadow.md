# G0 空间、圆角与阴影

下列为设计稿 px。小程序几何尺寸按 390px 主画板以约 `2rpx = 1px` 换算；字体保持 px，1px 分隔线保持物理 1px。不得为了对齐而在单页引入新的间距值。

| 用途 | 小程序 | 后台 |
| --- | --- | --- |
| 页面左右边距 | 20px | 24–32px |
| 主分区间距 | 24–28px | 24px |
| 卡片内边距 | 22–24px | 20–24px |
| 并列卡片间距 | 16–20px | 16–24px |
| 主要卡片圆角 | 20–24px | 12–16px |
| 次级控件圆角 | 12–16px | 8–12px |
| 主操作高度 | 48–52px | 40–44px |
| 底部导航图标 | 28–30px | 不适用 |

统一阴影为短柔阴影：`0 6px 18px rgba(7, 30, 73, 0.10)`；后台可降为 `0 4px 12px rgba(7, 30, 73, 0.08)`。相邻卡片必须露出底色，阴影不可连成整块。
