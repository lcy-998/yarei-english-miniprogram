# 视觉实现交接说明

## 单页实现顺序

1. 确认页面属于当前产品里程碑，且台账为“已批准”。
2. 从公共令牌与组件开始，不复制效果图像素或页面私有控件。
3. 按 `page-delivery-matrix.md` 引入生产素材；没有列出的位图默认不需要。
4. 先实现正常状态，再接 `05-states/` 的加载、空、失败、权限和业务异常。
5. 按 `06-responsive/` 验证小屏、字体、键盘、横屏、平板、弱网和冲突。
6. 按 `page-screenshot-acceptance.md` 截图与 `current` 主稿叠图复核，记录尺寸、颜色、排版、组件、素材、状态和横屏/平板差异，再执行真实交互和权限测试。

## 工程边界

- 页面只组合组件、绑定 view model 和维护页面级临时状态；业务规则仍在 service/domain。
- 基础图标使用项目 SVG/WXML/CSS 图标源；波形/时间轴/评分环/进度/图表由代码或 Canvas 渲染。
- 生产位图从 `03-assets/production/` 复制到目标工程目录后压缩；不得运行时引用 `visual-design/`。
- 页面主稿、组件板和状态板均不得进入小程序包或后台静态资源。
- M0/M1 默认不引入图标库、动画框架或第三方组件库；新增依赖先评审兼容性和包体收益。

## 素材接入

- Logo/吉祥物保持原比例和透明通道；不得滤镜改色、重绘或裁切面部。
- 虚构阅读封面和页图带 `demo-` 前缀；真实内容接入时按资源 ID/版本替换，不改变页面布局。
- 页图记录宽高、页序、版本和稳定资产键；OCR 文本不作为 S-04 可见正文。
- 透明空状态插画只作为辅助；错误原因、恢复动作和状态必须由组件文字表达。
- 小程序包体超限时优先分包、按需加载和压缩，不删除权限/错误状态或偷偷降低可访问性。

## 组件复用

- 导航、按钮输入、卡片列表、弹窗抽屉、媒体录音、任务状态和表格筛选分别以 `02-components/` 七张状态板为唯一视觉输入。
- 同一功能图标只有一个隐喻；角色差异通过密度、背景和装饰控制，不复制三套组件。
- 失败态恢复到可操作状态且保留输入；高风险写操作阻止重复提交。

## 验证与证据

- 自动：类型检查、组件/视觉契约、业务测试、素材清单 JSON、图片解码与缺失引用扫描。
- 微信：编译、Console/Network、390×844、375×812、键盘、200% 字体；媒体里程碑再验横屏、录音和播放。
- 后台：1440×900、1280×800、768×1024；表格横向滚动和抽屉操作可达。
- 报告只写实际执行结果；静态稿通过不等于运行时、真机、可访问性或用户评审通过。
- S-05/T-20 以已批准 `current` 为准；T-19/A-08 候选的具体审阅意见见 `g4-review-2026-09-29.md`，用户批准前不得按候选稿固化正式页面样式。
- M3 录音、媒体、AI、订阅消息、旋转和弱网的运行验收按 `docs/m3-test-baseline-2026-09-29.md` 留证；当前 M2 开发状态不构成 M3 开工或通过证据。

## 回退

- 页面视觉出现阻断时回退到上一个已批准 `current` 或 Git 提交，不删除历史稿。
- 生产素材以 manifest ID 和版本切换；不覆盖未知来源文件。
- M1 CloudBase 接入失败时回退 memory repository，不通过修改视觉隐藏错误。
