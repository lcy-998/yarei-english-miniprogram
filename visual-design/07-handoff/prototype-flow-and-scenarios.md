## 七类评审场景

| 场景 | 视觉来源 | 页面行为 |
| --- | --- | --- |
| 正常 | `04-pages/current/` | 正常数据与主要操作 |
| 空数据 | `05-states/common-loading-empty-error.png` | 保留导航和可执行入口 |
| 网络失败 | common 状态板 | 保留旧数据/输入并重试 |
| 无权限 | `permission-disabled-offline.png` | 不展示越权对象，返回安全入口 |
| 资源下架 | permission 状态板 | 新引用阻断，历史快照可读 |
| 映射缺失 | `media-recording-ai.png` | 定位题目并阻止审核/发布 |
| 已过期 | `task-lifecycle.png` | 显示逾期/补交规则，不篡改任务生命周期 |

场景切换器只进入开发/评审构建；正式产品不显示。
