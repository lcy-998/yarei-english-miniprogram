# 视觉设计令牌开发契约

> 来源：已批准视觉系统与 `01-foundations/`。开发不得从效果图采色或测量产生新的私有令牌。

## 色彩

| 名称 | 值 | 开发用途 |
| --- | --- | --- |
| `COLOR_PRIMARY` | `#1764D8` | 主操作、当前导航、关键链接、主进度 |
| `COLOR_PRIMARY_PRESSED` | `#0C4FB8` | 主操作按下 |
| `COLOR_TEXT_PRIMARY` | `#071E49` | 标题、正文、关键数字 |
| `COLOR_TEXT_SECONDARY` | `#596987` | 辅助文字与未选导航 |
| `COLOR_SUCCESS` | `#1FA968` | 完成、通过、有效 |
| `COLOR_WARNING` | `#F3B91C` | 提醒、点读与高亮 |
| `COLOR_URGENT` | `#E45A22` | 截止、逾期和需注意 |
| `COLOR_AI` | `#6542CE` | AI、录音与创意学习 |
| `COLOR_DANGER` | `#D9342B` | 错误与危险操作 |
| `COLOR_SURFACE` | `#FFF9F0` | 暖白内容表面 |
| `COLOR_PAGE_NEUTRAL` | `#F6F8FC` | 家长、教师与后台底色 |
| `COLOR_SKY` | `#76CBEF` | 学生/公共端顶部环境 |
| `COLOR_BORDER` | `#D9E3F5` | 输入边框和弱分隔 |

状态必须同时使用文字和图标；错误不得使用橙色代替红色，AI 紫不得代替权限或审核状态。

## 字体

- 小程序：系统中文无衬线字体栈；后台：`PingFang SC, Microsoft YaHei, Arial, sans-serif`。
- 页面标题 28/36px 700；区块标题小程序 22/30px、后台 20/28px 700。
- 卡片标题小程序 18/26px、后台 16/24px 600。
- 正文小程序 16/24px、后台 14/22px；辅助文字 14/20px 或 13/20px；标签 12/18px。
- 字体放大 200% 时允许纵向增长，禁止固定高度裁切；完整文本通过可访问标签读取。

## 几何

| 项目 | 小程序 | 后台 |
| --- | --- | --- |
| 页面边距 | 20px | 24–32px |
| 分区间距 | 24–28px | 24px |
| 卡片内边距 | 22–24px | 20–24px |
| 卡片间距 | 16–20px | 16–24px |
| 主卡圆角 | 20–24px | 12–16px |
| 次控件圆角 | 12–16px | 8–12px |
| 主操作高度 | 48–52px | 40–44px |
| 最小触控区 | 44×44px | 40×40px |

阴影：小程序 `0 6px 18px rgba(7,30,73,.10)`；后台 `0 4px 12px rgba(7,30,73,.08)`。相邻卡片必须露出底色。

## 响应式与安全区

- 小程序主视口 390×844，补充验证 375×812；必须读取微信状态栏、胶囊和 `safe-area-inset-bottom`。
- 后台主视口 1440×900，补充验证 1280×800；768px 平板侧栏折叠、表格横向滚动。
- S-04/S-05/S-07/S-09/T-20 横屏采用双栏/三栏，不丢页码、播放、录音、草稿和筛选状态。
- 图片 `cover` 只裁切装饰外缘，不裁切业务主体；页图使用适合阅读的 `contain`/可缩放容器。
