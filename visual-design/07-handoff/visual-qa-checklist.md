# 全项目视觉还原验收清单

> 执行时按 `page-screenshot-acceptance.md` 为每页保存主稿版本、运行条件、原始截图、叠图、差异与复测结论；本清单未勾选项不得因静态稿或自动契约检查通过而视为运行验收通过。

- [ ] 使用 G0 令牌，不从截图取色；主按钮、导航、成功、提醒、逾期和错误色符合定义。
- [ ] 页面左右边距、卡片内边距、圆角、主按钮高度和阴影符合基础规范。
- [ ] Logo 与吉祥物均来自生产素材，保持比例、透明通道和清晰边缘。
- [ ] 页面没有把文字、图标、按钮、进度或数据裁切成图片使用。
- [ ] P-01 与 S-01 的自然背景未遮挡卡片、胶囊、安全区或底部导航中央内容。
- [ ] 学生、家长、教师 Tab 的入口数量、顺序和选中态正确；A-01 使用侧栏与顶栏。
- [ ] G-01 仅提供只读操作；T-01 无吉祥物；A-01 无全屏卡通背景。
- [ ] 默认、按下、禁用、加载、成功、失败、空数据和无权限状态均可验证。
- [ ] 小程序在 390×844 与 375×812、字体 200%、键盘弹出时没有裁切关键操作。
- [ ] 后台在 1440×900 与 1280×800 下侧栏、表格、筛选和主操作可用。
- [ ] 与 P-01、S-01、G-01、T-01、A-01 主稿做叠图/截图对比；出现明显偏差时回到公共组件或令牌修正，而非单页打补丁。
- [ ] S-04 阅读主体是页图，不在页图外另行排版显示 OCR/抽取正文。
- [ ] S-05/S-07 的录音失败保留录音；AI 低置信度不展示伪分数。
- [ ] T-19/T-20/A-08 的上传、转码、审核、上架和片段映射状态分开表达。
- [ ] T-20 片段边界精确到毫秒，缺失/越界/零时长定位到具体题目并阻止提交审核。
- [ ] A-08 驳回原因、可见范围、并发冲突和操作失败均保留输入并有恢复路径。
- [ ] 生产位图只来自 `03-assets/production/`；基础图标、波形、时间轴、状态和文字均由代码渲染。
- [ ] 横屏切换保留页码、媒体进度、录音、草稿和筛选；平板折叠菜单后主操作仍可到达。
