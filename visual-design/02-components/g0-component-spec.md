# G0 公共组件规格与状态

> 本文是效果图之外的实现依据。基础图标一律用 SVG 或 WXML/CSS 实现；不可从页面截图裁切图标。

## 导航与安全区

| 组件 | 规格 | 页面 |
| --- | --- | --- |
| 小程序顶部区 | 使用系统状态栏和微信胶囊实测高度；内容不与胶囊重叠 | P-01、S-01、G-01、T-01 |
| 学生 Tab | 首页、阅读、班级、我的；四等分，当前项为 `COLOR_PRIMARY` | S-01 |
| 家长 Tab | 首页、孩子、报告、我的；四等分，当前项为 `COLOR_PRIMARY` | G-01 |
| 教师 Tab | 工作台、任务、教材、学员、我的；五等分，当前项为 `COLOR_PRIMARY` | T-01 |
| 后台侧栏 | 左侧固定导航、账号区在顶栏；当前项以浅蓝底和深蓝文字区分 | A-01 |

Tab 图标视觉尺寸 28–30px、标签间距 8px；未选中使用 `COLOR_TEXT_SECONDARY`。导航项需要按下态，按下仅改变色彩/背景，不改变布局。

## 表单与按钮

| 组件 | 默认 | 按下/聚焦 | 禁用 | 处理中 | 错误 |
| --- | --- | --- | --- | --- | --- |
| 主按钮 | `COLOR_PRIMARY`、白字、48–52px 高 | `COLOR_PRIMARY_PRESSED` | 低饱和蓝、不可点 | 显示转圈与“处理中”，阻止重复提交 | 恢复可点，保留输入并显示原因 |
| 次按钮 | 暖白底、蓝色描边/文字 | 浅蓝底 | 灰化 | 同上 | 同上 |
| 输入框 | 暖白底、`COLOR_BORDER` 1px、48–52px 高 | 深蓝描边 | 浅灰底 | 不适用 | `COLOR_DANGER` 描边与字段下说明 |
| 文字按钮 | 蓝色文字、无实底 | 浅蓝点击底 | 灰色 | 不适用 | 不适用 |

P-01 登录失败后必须保留手机号；密码可清空但不可自动覆盖。每个禁用操作都显示不可操作原因。

## 卡片、数据与反馈

- 暖白 `COLOR_SURFACE` 是内容主承载层；学生端使用 20–24px 圆角，教师和家长减少装饰，后台使用 12–16px 圆角。
- 任务卡、统计卡与入口卡均只使用一个主图标或一幅内容插画；数据、进度与状态由真实组件绘制。
- 状态标签：成功使用绿色，提醒使用黄色，截止/逾期使用橙色，错误使用红色。不能只依靠颜色表达状态。
- Toast 位于顶部安全区下方；成功、失败均包含简短文字。加载优先使用骨架屏；局部写操作使用按钮内加载。

## 吉祥物与背景

- 官方吉祥物只从生产目录引用，保持透明通道；不得重绘、滤镜变色、拉伸或裁切面部。
- 蓝色学习吉祥物用于 P-01、S-01 的欢迎/学习引导；粉色口语吉祥物预留给后续跟读/口语反馈，G0 主页面不强制出现。
- `student-public-natural-background-v1.png` 只用于 P-01 与 S-01 的环境层。G-01、T-01、A-01 使用 CSS 色面和组件层级，不铺满卡通场景。
