# G0 状态板规格

> 状态由组件渲染，不另生成含业务文字的整页图片。以下状态覆盖 G0 母版在开发与原型中的最小交付。

| 状态 | 视觉表现 | 恢复动作 | 适用页面 |
| --- | --- | --- | --- |
| 首屏加载 | 导航与卡片骨架；背景可保留但不显示伪数据 | 数据完成后原位替换 | 全部 |
| 空数据 | 轻量空状态插画或代码图形、说明与单一行动按钮 | 进入可执行入口或返回 | S-01、G-01、T-01、A-01 |
| 加载失败 | 保留已成功加载内容；失败区显示原因与“重试” | 重试对应请求 | 全部 |
| 无权限 | 锁定图形、明确原因、返回首页 | 返回，不显示越权数据 | 全部 |
| 登录失败 | 输入框错误描边和字段下说明；保留手机号 | 修正后重新登录 | P-01 |
| 提交中/成功/失败 | 按钮内加载；成功 Toast；失败后恢复可点并保留表单 | 重试或继续编辑 | G0 后续流程通用 |
| 禁用 | 降低对比度且补充不可用原因 | 满足前置条件后启用 | 全部 |

每个状态均遵守安全区、同一令牌、同一圆角与同一图标笔画。状态切换不得改变用户正在填写的内容或滚动上下文。
