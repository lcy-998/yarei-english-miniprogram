# M2 课堂录音任务契约

基线：`product-requirements-core.md` 0.26.1 与 `page-interaction-spec.md` 0.26.1。此文记录本地实现及联调条件，不授权部署、规则发布或真实素材导入。

## 发布素材与边界

- 教师仅能选择本组织、授权班级可用、`published` 且未删除的 `learning_resources` 录音文字提示。提示快照须为 `promptKind: "text"`、`requiresVideo: false`，并含 1—500 字提示文本。发布固化提示内容与资源版本。
- 阅读、单词、习题和无需视频播放的录音可进入 M2 发布；听力、看视频及任务视频配音仍由服务端拒绝，待 M3 的播放验证、音频对位和审核能力具备后开放。
- T-18 录音提示按授权班级与关键词分页查找，T-06 回填时再次核验资源。没有已授权提示时如实显示空状态，不导入真实教材或音频。

## 学生录音与提交

- S-09 用微信录音管理器录制 MP3，支持本机试听、重录、上传失败后在当前页面保留录音并重试。单条限制 1 秒至 5 分钟、20 MB。
- `task-recording-command.begin` 为本人当前任务项创建带组织和本人摘要的 staging 路径；`submit` 由服务端下载 staging 文件，解析 MP3 时长、大小及编码，复制到独立私有路径，保存哈希、文件引用、时长和大小。前端传来的时长和大小不参与信任判断。
- 学生提交任务时，`submission-command.submit` 重新核对录音记录与任务、任务项、班级、学员、资源版本及下一提交版本一致，并固化到该提交版本的只读证据。未封存、他人或旧版本录音不能成为有效提交。重复操作使用操作 ID 和版本号保护。
- 页面重新打开后查询本人当前提交轮次的录音记录；已上传录音可恢复到作答项。本机文件丢失时需重新录制。云端封存失败不会删除本机录音。

## 教师检查、评分与家长

- T-08 按当前或历史提交版本展示录音证据；教师按授权班级、正式提交版本与任务项核验后获取 60 秒临时试听链接，并将成功访问写入 `operation_logs`。未授权、未进入提交或审计写入失败时不返回链接。
- 录音由教师按内容项逐项评分（0—100 分）。录音与阅读、单词或客观题混合时，服务端从发布快照读取各项权重，合并可信自动分与教师逐项分，固化最终总分及人工分明细；前端不能自行声明加权总分。历史点评中的逐项人工分只对授权教师展示，学生与家长仍看正式总分。旧 M1 汇总评分任务继续沿用原兼容路径。
- 家长端只读查看孩子的任务状态和已发布反馈；录音临时链接不向家长开放。

## 存储与部署门禁

- 新增 `task_recordings`、`task_recording_operations` 集合及两条云函数配置模板。`docs/m2-task-recording-storage-rule.example.json` 仅是**不可直接发布的规则片段**：CloudBase 存储规则作用于整个环境，必须先读取现行规则，再将暂存写入条件与其他已授权路径合并，保持既有素材读取和私有文件拒绝边界；非生产规则发布已纳入 2026-09-27 M2 统一授权，仍须先验证路径、所有者和大小限制。
- 云端函数部署、集合/索引创建、存储规则发布、虚构素材种子导入均需各自的用户授权。当前仅完成本地代码和测试；微信开发者工具、真机、CloudBase 文件上传/临时链接和音频权限兼容尚未验证。
