# 雅睿英语视觉系统基线

> 视觉方向名称：自然高饱和卡通 1.0  
> 状态：视觉风格已确认；页面排版按审批门逐页确认  
> 适用范围：微信小程序学生端、家长端、教师端及独立管理后台

## 1. 视觉目标

雅睿英语使用明亮、亲和、具有学习活力的自然高饱和卡通风格。页面以暖白内容表面和清晰信息层级为主体，天空、树木、花草只构成轻量环境层；品牌蓝、黄色、橙色、绿色和紫色用于功能和状态强调。

视觉必须同时满足：

- 低龄学生容易理解，但不呈现幼儿园海报感；
- 教师和家长页面保持同一品牌，但明显降低装饰密度；
- 页面有呼吸感，卡片和功能区域不拥挤；
- 插画不绑定动物园、城市、节日、地域或具体教材；
- 所有页面可用微信原生 WXML/Less 和常规图片资源实现。

## 2. 不可漂移的视觉特征

1. 暖白卡片是主要内容承载层，不能使用整屏蓝色内容底。
2. 天空蓝主要位于顶部或页面间隙；树木、草地、花朵位于外缘，不进入表单、播放器或正文。
3. 官方吉祥物只承担品牌欢迎、学习引导、口语反馈等辅助角色，不承载业务数据。
4. 非官方小动物为可选远景点缀，单页最多 1 只、面积不超过画面 2%，不得进入业务卡片。
5. 每页只有一个主要视觉焦点和一个最高优先级操作。
6. 单张业务卡只使用一个主功能图标或一幅内容插图，不堆叠星星、字母块和多个装饰图标。
7. 微信胶囊、顶部安全区、底部导航、图标笔画和卡片圆角必须由公共组件统一实现。

## 3. 色彩令牌

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `color-primary` | `#1764D8` | 主按钮、当前导航、播放进度、关键链接 |
| `color-primary-pressed` | `#0C4FB8` | 主按钮按下态 |
| `color-text-primary` | `#071E49` | 标题、正文、关键数字 |
| `color-text-secondary` | `#596987` | 辅助文字、未选中导航 |
| `color-success` | `#1FA968` | 已完成、通过、有效结果 |
| `color-warning` | `#F3B91C` | 点读高亮、提醒、激励 |
| `color-urgent` | `#E45A22` | 截止时间、未完成、需注意 |
| `color-ai` | `#6542CE` | AI、跟读、录音和创意内容 |
| `color-surface` | `#FFF9F0` | 主卡片和大面积内容表面 |
| `color-nature-deep` | `#3FAF57` | 树叶、草地深层 |
| `color-nature-light` | `#69C95A` | 树叶、草地浅层 |
| `color-sky` | `#76CBEF` | 顶部天空和轻背景 |

错误与危险状态使用独立错误色，不使用橙色代替。正文、按钮和状态文字达到 WCAG AA。

## 4. 空间、圆角与阴影

| 项目 | 小程序 | 管理后台 |
| --- | --- | --- |
| 页面左右边距 | 20px | 24–32px |
| 主要分区间距 | 24–28px | 24px |
| 卡片内边距 | 22–24px | 20–24px |
| 并列卡片间距 | 16–20px | 16–24px |
| 主要卡片圆角 | 20–24px | 12–16px |
| 次要控件圆角 | 12–16px | 8–12px |
| 主操作高度 | 48–52px | 40–44px |

阴影使用单一方向的短柔阴影。相邻卡片之间必须露出背景，不允许阴影连接成连续白块。

## 5. 图标与插画

- 功能图标容器统一为 56–64px，图形占容器 60%–65%。
- 图形四周至少保留 12–16px；图标与文字至少间隔 14px；距卡片边缘至少 16px。
- 底部导航四等分，图标视觉尺寸 28–30px，图标与标签间隔 8px。
- 同一功能只能使用一种图形隐喻，禁止跨页面更换样式或笔画粗细。
- 图标优先使用可维护的 SVG 或 CSS/WXML 图形；ImageGen 不负责生成基础图标系统。
- ImageGen 只用于吉祥物动作、自然背景、复杂空状态和难以用代码表达的插画。
- 所有生产插画必须独立导出，不把按钮、业务文字、进度或状态烘焙进图片。

## 6. 角色差异

- 学生端：允许官方吉祥物和自然环境，信息密度最低。
- 家长端：保留自然背景色和圆角，减少大插画，以概览和反馈为主。
- 教师端：保留品牌色、图标和圆角；背景更克制，优先保证任务操作效率。
- 管理后台：浅中性背景、白色工作区、清晰表格；卡通元素只用于空状态和品牌识别。

## 7. 一致性验证

每张页面效果图必须同时引用：

1. 本文档；
2. 已批准的角色母版；
3. 当前公共组件状态板；
4. 对应页面的 `page-interaction-spec.md` 规格。

视觉验收检查色值、间距、图标、圆角、阴影、微信胶囊、底部导航、吉祥物比例、装饰数量和文本准确性。任一项不符合时不得进入 `current`。
