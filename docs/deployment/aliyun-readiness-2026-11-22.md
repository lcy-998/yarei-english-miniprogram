## 性能发现、修复与限制

原 SQLite 查询先取整集合、逐条 JSON.parse 后过滤。现将安全的字符串、布尔值、null 条件下推 SQLite，复杂条件继续执行原 JSON 比较；增加 collection/organizationId/type/status/id 目录索引。没有缓存身份、权限或业务数据，没有放宽安全检查。

测试在同一阿里云服务器的独立恢复副本、loopback 3211 执行，维护任务关闭，复用同一学生身份交替读取阅读和词包目录。不是 100 个真实账号、真实手机公网媒体/写入/AI 混合压测。失败即停止升压，临时服务结束后停止；两个任务创建的恢复目录随后清理，证据和正式备份保留。
