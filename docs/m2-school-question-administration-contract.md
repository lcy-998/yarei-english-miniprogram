# M2 A-06 学校习题库管理本地合约

后台 A-06 只管理既有 `learning_resources` 中 `type=exercise` 的固定题目。题干、选项、标准答案和解析仅在预览中展示，不提供改写接口。真实题库导入和版权仍按产品基线另行处理。

## 管理能力

- 列表按关键词、题型、班级和状态筛选，20 条一页加载；详情展示完整题目和标准答案。
- 管理员可设置全校或指定班级可见；指定班级至少一个且必须为当前组织中启用的班级。
- 单题和最多 20 题一批可上架、下架或调整可见范围；操作前二次确认、填写原因，并带每道题的当前版本。任何一项失效时整批回滚。
- 服务端检查 `admin` 角色、`organization.read` / `organization.manage` 权限及当前组织/班级范围；小程序教师仍只能浏览、预览和引用当前已上架且有权访问的题目。
- 管理写入只改变可见范围、上架状态、更新时间和文档版本，不改变 `contentVersion` 或题目正文。历史任务和提交使用发布时快照。
- 操作标识、请求指纹和结果写入 `question_admin_operations`，成功操作同时写 `operation_logs`。重复请求返回同一结果，复用操作标识但变更内容会报冲突。

## 联调边界

当前完成本地服务、独立管理后台页面和虚构数据验证。`question_admin_operations` 已配置仅服务端读写，现有 `learning_resources` 和 `operation_logs` 保持仅服务端读写。新代码已部署到非生产 CloudBase，虚构题目列表/详情的管理员令牌读取通过；后台写入、并发容量、浏览器视觉和真实设备仍未验收。
