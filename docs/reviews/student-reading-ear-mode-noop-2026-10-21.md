# S-04 同步课本磨耳朵无响应修复

用户反馈同步课本阅读页点击“磨耳朵”没有效果。检查发现任务阅读状态下按钮可见且已取得冻结章节音频映射，但 `chapterAudioContext` 直接拒绝 `taskMode`，`enterEarMode` 又只在播放成功后才切换视图，因此点击后页面保持原状。

本轮让任务模式使用本人当前任务项取得的历史冻结音频映射；短期地址到期时只从同一任务授权查询刷新，不退回当前公共资源地址。教师只读审阅仍不能播放学生任务音频或写进度。点击磨耳朵后立即进入隐藏文字的播放视图，准备中和播放失败有可见说明及重试入口。任务模式暂禁章节音频拖动，避免现有客户端滑块前跳未核验位置；自主阅读拖动保持原规则。离开磨耳朵后播放位置不重置。

微信开发者工具模拟器以虚构同步课本任务状态点击真实页面按钮，读回 `taskMode=true`、`earMode=true` 且播放控件出现；截图见 `workspace/m3-acceptance/2026-10-21/S-04-ear-entry-task-mode.png`。阅读音频、页图恢复及教师预览定向测试 3 文件 18 用例通过，小程序 TypeScript 类型检查通过。模拟器数据为虚构展示状态，尚未用已登录学生账号播放真实章节音频或在真机验收。本轮未修改云端素材、任务快照或云函数。
