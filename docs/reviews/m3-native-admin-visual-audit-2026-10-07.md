- 当前 A-01 默认字号下五个入口可见，最后一项未被底栏遮挡；搜索和列表未见横向溢出。该结论只覆盖本次 390×844 模拟器的缩小截图。
- A-02/A-03/A-04/A-06/A-08 当前代码的正常态、长列表、打开表单／详情、375×812、844×390、812×375、200% 字体、键盘、真机安全区仍未通过视觉验收；开发者工具自动化跳转超时须单独排查，不能由旧图推断通过。
- A-08 页面规范要求公共素材展示来源学校与源版本，当前摘要/页面只有记录版本和证据布尔值；这是数据契约缺口，需先补字段再验视觉。

## 本轮页面调整记录（2026-10-07）

本节记录上述检查后的代码修改，不改变前文截图的取证时间，也不表示视觉验收完成。各代理只修改负责页面的 WXML/Less，主任务修改六页共用样式、打开表单和详情后的滚动定位。

- A-01/A-02/A-03：统一导航标题与内容左右边界，压缩 A-01 重复头部；长账号编号换行并退居辅助信息；账号和班级操作表单加入固定定位点。打开表单或绑定关系后滚动到相应区域，关闭时返回列表原位置。
- A-04/A-06：保存与重置、撤销分开排布；教师编号和审计文字可换行；题目选择、预览、筛选和批量按钮扩大触摸区域，窄屏时允许换行。
- A-08：素材详情加入定位点，打开后滚动到详情、关闭后返回列表；试听题号与时段分行，播放器和按钮适应窄屏；“提交问题”为主按钮，“下架素材”为次级危险按钮。下架确认逻辑保留。
- 共用：搜索框、筛选项、表单按钮及行操作扩大触摸区域；辅助文字加深；底部留白纳入安全区。A-08 的独立底距已和共用值对齐。

已在 `workspace/` 实际运行 `npm run typecheck`、`npm run visual:check` 和 `npx vitest run tests/services/native-admin-access-contract.test.ts`，均通过；最后一项为 3 个用例。`npm run admin:check` 单独运行通过（网页后台 49 个测试及构建）。整套 `npm run check` 未通过：全量测试 1313 项中 2 项失败，分别是配音评分推理失败后重试的版本冲突、云函数部署模板比注册清单多出三个发音函数；其余 1311 项通过。两个失败均不在本轮六页视觉修改范围内。`visual:check` 是静态契约检查，不是微信运行视觉验收。当前六页的 375×812、横屏、200% 字体、键盘及真机截图仍待复核；A-08 来源学校／源版本的数据契约缺口和 A-06 题目摘要字段也未由本轮排版调整解决。
