# 班级教材发布误判资源不可用修复

用户从 T-13 添加同步课本后发布，收到“该资源当前不可用于新操作”。现有产品规则允许教师查看、选择已发布且有效的同步课本，发布对象仍限本人有教学权限的班级。

只读核对唯一已确认的非生产 CloudBase：`teacher-textbook-query` 已按当前规则返回可选课本，而 `teacher-textbook-command` 仍是 2026-09-28 的旧代码。旧保存分支要求 `book.grade === target.grade` 且课本在旧班级可见名单内；现有虚构三年级班级保存数字年级 `3`，较新的同步课本保存“三年级”等文字年级，即使资源仍为 `published` 也会被旧条件拒绝。检查时目标班级配置为版本 1 的空草稿，未改写已有课本安排。

在免费、超额计费关闭的非生产环境，只对 `teacher-textbook-command` 的线上原包移除上述两项过时条件；教师身份、班级授权、`task.publish`、同组织资源、发布态、内容版本、章节课次完整性和幂等校验仍保留。更新前后代码 SHA-256 分别为 `82f7c1587b2ba5886ca7d234a010fd4fdb20b782dd65771eb442e17590f60707` 与 `a36f76547349698ab7049608b963350f6bfaa4ffc58fb6c86c204574f3b39fb5`。线上原包已下载作精确回退，函数读回为 `Active`，运行配置和路由未变。预检时函数调用、数据库写、读指标分别为 4867、886、10626，未开通新费用。

本地 `teacher-textbook.test.ts` 新增“目录可选的不同年级／旧班级名单课本可发布到本人授权班级”回归用例，10/10 通过；CloudBase TypeScript 类型检查通过。部署后只读核对原班级配置仍为版本 1 空草稿。

尝试用归档虚构教师凭据做云函数发布并精确回收探针时，凭据认证失败，**没有执行发布调用，也没有新增配置或操作回执**。因此本轮尚不能报告已登录教师页面发布通过；需教师在当前页面重试，或更新非生产演示账号凭据后再做真实云函数闭环。若仍失败，应保留当前已选课本并记录具体课本与班级以进一步核对版本和资源状态。
