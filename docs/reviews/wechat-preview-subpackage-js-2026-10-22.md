# 微信预览包主包脚本检查修复（2026-10-22）

## 现象与原因

微信开发者工具在预览上传前阻止打包，报告主包 `shared/` 中的四个 JavaScript 模块只供分包使用：习题组归并、习题分段、视频题评分草稿和教师评分草稿。它们由分包页面跨根目录导入，造成代码质量检查识别为主包携带分包专用脚本。

## 修复

- 将习题组归并与分段、视频题评分逻辑分别放入实际使用的学生/教师/学生媒体分包，并改用分包内相对导入。
- 教师评分草稿模块按分包本地化；跨分包返回时通过 `yarei_teacher_review_score_draft` 本地存储键共享草稿，并校验当前 `sessionId`。清空草稿时移除该键，避免账号切换后复用旧值。
- 用户再次运行预览检查后又报告 `exercise-pack-title.js` 与 `review-task-state.js`。将习题标题逻辑改为学生/教师分包内完整实现，学生任务详情改用本地实现；视频任务评分改为使用学生媒体分包内的评分规则。与前一批相同，原主包源文件不再被小程序运行代码跨根目录引用。
- 原 `miniprogram/shared/` 源文件仍保留供现有测试导入，不再由小程序运行代码引用。

## 验证与限制

- 两轮修复后 `npm run typecheck` 通过。
- 微信开发者工具静态代码包检查和预览上传尚未复测；运行本地预览/上传需要在用户的开发者工具会话中确认最终包状态。
