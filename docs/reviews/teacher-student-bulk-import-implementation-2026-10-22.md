# T-02 学员批量导入实现与非生产接线（2026-10-22）

## 已完成

- 保留固定 UTF-8 CSV 模板、本地预检和服务端逐行校验；服务端以当前教师会话、实时 `student.import` 授权和班级授权为准。
- 将批量导入接入 CloudBase 函数 `teacher-student-import-command`。Auth 外部身份使用确定性操作 UID；同一导入操作可恢复，重复编号/手机号拒绝；业务资料以事务写入用户、身份、角色、班级关系、学号保留记录和审计。业务提交失败会阻止本次创建但尚未关联业务资料的身份登录。
- 将函数放入单独的受保护构建包；不并入标准 M1/M2 函数包。账号创建沿用 A-03 已使用的服务端 Manager Auth capability，不在前端保存凭据或密码。密码仍由学生本人经 P-03 的手机号验证流程首次设置。
- T-02 的预检和正式错误结果均可保存为 CSV；设备不支持系统文件保存时，自动复制错误 CSV 到剪贴板。错误文件仅含行号、字段、错误码和说明，不含姓名、学号、手机号或学生 ID。
- 优化服务端名单读取：每次批量操作只扫描一次既有学生编号；每行 Auth 操作仍在教师每行权限复核后执行。
