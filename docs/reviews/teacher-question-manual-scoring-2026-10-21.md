# 教师习题与视频主观题评分（2026-10-21）

## 修复范围

- 教师从 T-08 打开 S-15 习题提交时，在每道需人工评分的题目下方输入 0—100 分；同一题组的主观题可分别评分。返回快速点评后逐项草稿恢复。
- 教师从 T-08 打开 S-14 视频提交时，在每道待教师评分的视频题下方输入 0—100 分。客观题沿服务端核对的正确/错误结果记 100/0 分；所有题等权合成视频任务项分。未完成评分、非法分数或未核对的客观结果不给合成分。
- T-08 将视频项人工分与其余任务项的自动分、人工分按已发布任务权重合成预计作业总分，并在作业概览与打分区显示。正式发布使用现有服务端 `itemScores` 校验及计分，缺项不允许发布。
- 教师总览与学生原作答页共享当前会话的未发布评分草稿；按提交版本隔离视频逐题草稿，切换账号后清除。

## 验证

- `npm run typecheck` 通过。
- `npm run visual:check` 通过。
- 六个定向测试文件 34/34 通过，覆盖习题组逐题输入、视频客观与主观合分、跨分包草稿、权重总分和错误分数拦截。
- 微信开发者工具 CLI 已打开工程；未使用已登录虚构教师完成点击和正式发布流程，真机未验收。

## 当前数据口径

正式反馈在现有服务端按任务项保存人工分及最终总分。视频逐题输入在未发布阶段保留于教师会话；本次不改变服务端反馈数据模型，正式反馈尚不提供逐道视频主观题分数回看。后续若要求逐题评分审计或跨设备回看，需扩展受控反馈记录与读取投影。
