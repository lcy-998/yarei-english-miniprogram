- A-01—A-08 的 390×844 手机候选图和无权、冲突、驳回、撤权状态图见 docs/reviews/m3-native-admin-mobile-visual-review-2026-10-03.md。图像已实际渲染和抽样检查，仍是候选，不是已批准的 current 主稿。
- T-19/T-20 真实扫描/转码的零增费可行性及云端付费候选、规格和无法承诺总价封顶的原因见 `docs/reviews/m3-teacher-media-cloud-decision-2026-10-03.md`；当前没有可执行的媒体云端处理授权。
- Storybooks Canada 最小绘本点读候选的本地 10/10 音频哈希和 8 段对齐通过，状态仍为 pending_review；版权署名、人工试听和云端变更边界见 docs/reviews/m3-reading-audio-binding-review-2026-10-02.md。现有资源的 copyrightStatus=demo，不能据此开放正式点读。
- Qwen3-0.6B Q4_0 模型文件仅做 D 盘静态哈希核对；用户指定模型运行全在云端，因此没有本机推理结果。内部云端基准的独立函数、费用、额度和回退见 docs/reviews/m3-qwen-cloud-only-benchmark-review-2026-10-02.md，该包尚未执行。
- 2026-10-03 又静态核对 llama.cpp `b11345` 官方 Ubuntu x64 CPU 包：17,551,918 字节且 SHA 与 GitHub 发布记录一致，解包常规文件 45,388,206 字节；与 428,970,080 字节模型合计 474,358,286 字节。目标云函数的 OpenSSL/C++ ABI、最终包装、内存/额度与云端推理质量仍未通过，不能把包体有余量称为 AI 建议功能通过。
- T-07/T-09 首批四个现有函数的拟定非生产差异、虚构联调与精确回退见 docs/reviews/m3-teacher-t07-t09-nonproduction-review-2026-10-03.md；目前仅是草案，没有执行授权。
- T-02 真实建号仍需确定受保护的管理端运行边界。[CloudBase 管理端用户接口](https://docs.cloudbase.net/en/api-reference/manager/node/user)现有 `createUser` 属管理 SDK 5.0.0 起的能力，示例由服务端凭据初始化；本项目当前业务云函数使用 `@cloudbase/node-sdk` 3.18.3，其 `auth()` 类型没有创建用户方法。不能把小程序登录 SDK 的注册接口冒充管理员批量建号，也不能从现行六项密钥中临时取凭据。待明确独立权限和费用后再接正式 Auth 管理适配。
- 六项现行非生产业务密钥风险仍按协调记录处理。本文的本地通过不授权部署新的 M3 函数、创建集合、真实教师赋权或改变既有账号绑定。非生产执行须有具体审阅包和用户对该包的一次明确授权。
