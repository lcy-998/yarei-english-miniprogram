## 2026-10-21 实际错误与账号门槛

- 用户再次在开发者工具完成验证码验证与新密码提交，页面仍显示通用错误。网络面板捕获 `XHR reset?client_id=...` 返回 HTTP 404；本地固定 SDK 的旧 `resetPassword` 方法指向 `/v1/reset`。由于窗口切换时模拟器再次启动，未能安全读出该请求响应体，404 尚不能区分“手机号未对应 Auth 用户”和“旧重置接口不可用”。
- 用户确认接收验证码的号码“不确定或是其他号码”，不是已明确可登录的三角色演示账号。原客户端发码时未要求目标账号存在，理论上可先发送和验证验证码，最后设密才发现没有对应身份账号；这与本次现象相符，但不能据此把 404 的具体云端原因记为已证实。
- 本地修复将找回验证码请求限定为 CloudBase `target: USER`，并在响应明确 `is_user: false` 时停止流程、提示联系管理员核对账号；不新增账号、不放宽登录。官方发送验证码接口规定 `USER` 目标必须已有账号。相关定向测试 23 项、小程序 TypeScript 检查通过；本轮没有再次发送短信或完成真实设密闭环。
