## 当前云端及共通验收状态

- 2026-10-07 只读预检：五个原生管理函数为 `Active`，非生产环境为个人版且关闭超限按量；现有虚构管理教师仍持有九项旧权限，包括已取消的教材、任务、草稿恢复权限。新六页代码尚无本包部署证据；不得把函数 Active 当作新功能已上线。
- 新账号操作集合只读检查为不存在；本地开户默认无可信 Manager provider 时返回 `SERVICE_UNAVAILABLE`，不会创建半账号。
- 公共媒体、习题、阅读和词包的跨校投影、源下架及历史任务读取已有本地合同；受控 `apply`、云端索引、真实来源/版权资料与各校教师/学生页面尚未验收。旧私有资源不会因本地代码自动公开。
- 开发者工具 CLI 曾打开工程，但自动化页面读取超时；没有新六页普通编译、已登录写入、横屏、弱网或真机通过证据。A-08 视觉台账仍为“需修改”。
- 最近一次根完整检查为 1298 项中 1297 项通过，唯一失败是并行跟读功能的旧重试版本测试；已确认与管理/公共素材无调用依赖。不能据此报告根 `npm run check` 全通过。账号首设改动后仅运行了相关类型检查和定向测试，尚未重跑根完整检查。
