# 教师私有视频直传改造与验收记录（2026-10-17）

## 已确认口径

用户确认教师先在手机本地准备可直接播放的 MP4，再上传并布置。教师私有视频不做云端转码及原文件/产物安全扫描；中央资产库的原有门槛不变。服务端仍核对真实文件字节、200 MB / 10 分钟上限、H.264 视频与可选 AAC 音频、教师所有权和教学关系，并将通过校验的文件复制到私有不可覆盖路径，保存哈希与版本证据。题目、答案和视频继续冻结到任务快照。

## 本地实施与验证

- 既有 `task-command` 复用 `DirectMp4PrivateVideoProcessor`，直接处理上传的暂存视频，无需新增工作函数。上传接口返回 `ready` 或 `failed`；失败保留草稿和暂存文件供重试。
- 私有视频发布校验接受服务端生成的直传证据；中央素材仍要求扫描和转码证据。
- T-21 提示只接受兼容 MP4，校验通过后可直接进入 T-06。现场拍摄仍受当前微信选择接口的 30 秒限制，较长视频由手机相机录好后从相册选择。
- 真实本地 MP4（含 AAC 音频）和构造的格式错误、超长文件测试通过。后端 `npm run check`：180 文件、948 用例通过；小程序 `npm run check`：335 文件、1452 用例通过，后台 49 用例及构建通过。定向回归 3 文件、12 用例通过。
