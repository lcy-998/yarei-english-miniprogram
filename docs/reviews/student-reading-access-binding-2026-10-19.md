# 学生阅读目录可见但详情提示无权（2026-10-19）

## 发现与修复

- 学生子包保留了一份独立的 M1 service 单例，启动时的 CloudBase repository 配置只写入根 service。阅读专区的目录使用 CloudBase，而阅读详情仍可能通过子包单例访问内存演示 repository。演示学生 ID 与内存固定账号不符时，返回“无权阅读该内容”。这也影响使用同一子包 service 的学生首页资料、单词页和任务详情的 M1 读取。
- 将学生子包的 M1 service 改为重导出根 service，让上述页面共享启动时选定的 repository；未放宽服务端权限，也未修改书籍、学习进度或账号数据。

## 验证

- 新增共享绑定测试：配置根 repository 后，学生子包的阅读调用进入同一 repository；通过。
- 阅读目录回归测试通过，小程序 TypeScript 类型检查通过。
- 既有非生产环境以虚构学生身份，通过服务层只读核对五类目录：同步课本 9 本、绘本 18 本；27/27 本均可读取详情及本人进度，其他三类当前为 0 本。没有业务写入或权限扩大。
