# 听力作业完成后仍提示题目未答：修复与验证（2026-10-17）

## 问题核对

用户截图中的提示为“请完成‘Happy Birthday, William Shakespeare!｜活动与日常听力’的全部题目”。在既有非生产环境只读核对：对应历史任务仍为可见的活动任务，发布快照要求 1 道简答题；快照的题目 ID 与页面渲染题目 ID 一致。原素材现已下架，但历史任务使用发布快照，不应因素材状态变化改写题目要求。

客户端存在两条不一致的答案路径：任务进度读取本轮本机草稿，正式提交在该媒体项仍标为当前活动项时优先只读页面内存答案。页面内存可能已被清空或过期，于是进度显示已完成，提交却返回“全部题目未完成”。此外，本机存储写入失败时，独立听力页虽保留输入，返回任务详情后原实现无法读取该输入。

## 修复

- 听力、视频和任务详情共用同一媒体答案草稿模块；作答时同时保留限于当前登录会话的内存副本和本机持久副本。本机写入失败仍可在同一会话返回任务详情提交；退出或切换账号会清除内存副本。
- 正式提交合并云端草稿、当前媒体页面答案和最新本轮草稿，避免旧的活动项内存覆盖已完成答案。
- 正在同步答案时点击提交会明确提示“作答正在同步，请稍后再提交”。
