## 本次本地实现范围（按 0.79.0 延迟评分规则）

- 学生端沿用 S-05 录音、试听、重录、封存和 `processing` 轮询；评分仅从可信服务端快照取得参考文本，录音失败时保留本机副本。
- 服务端以持久 outbox/CAS 作业受理评分，使用独立 HMAC 事件派发内部 worker。worker 每次执行前、推理后和结果落库前重新核验学生身份、授权版本、任务/阅读快照；重复事件不能重复计分，系统失败最多自动重试一次。
- Vosk 内部函数通过禁客户端调用的 SCF `RequestResponse` 路径运行。Node worker 的长请求设置为单次最多 290 秒并禁止自动重发；有限等待/平台超时后用作业状态和 outbox 恢复，不让页面请求直接执行模型。
- 学生本人可查尝试与试听本人有效录音；教师只对当前授权班级的正式提交读取试验结果和受控试听；家长仅见安全状态摘要，不见试验分、录音 ID 或私有地址。
- 标准结果为 0—100 总分及发音、流利度、完整度维度。Vosk 分数是代理指标；实现质量门槛、儿童样本质量评估和正式评分审批由用户后续测验/评审决定。

## 配置及部署门槛

- 只使用虚构学生/教师、原创合成 MP3 和已核准的非生产资源；不采集真实儿童录音。评分质量测验由用户后续进行，当前实现与云端合约检查不宣称质量通过。
- 运行时所需专用配置键为 `VOICE_INTERNAL_SECRET`、`VOICE_ALLOWED_MEDIA_HOST`、`VOICE_WORKER_LEASE_MS`（默认 330000 ms，必须大于 290 秒推理等待及 worker 超时窗口）、`TENCENTCLOUD_SECRET_ID`、`TENCENTCLOUD_SECRET_KEY`、`TENCENTCLOUD_SESSION_TOKEN`（可选）、`SCF_REGION`、`SCF_NAMESPACE`。代码只从服务端环境读取，不把值写入仓库或日志。
- 当前提交没有提供可用于 TC3 的 SCF 凭据，也没有本次审阅的实时套餐额度、函数配置/路由快照和新费用估算；旧函数密钥风险按既有用户决定保持未解决。本文件不授权读取、复制、轮换或新增任何密钥。若经审查的最小权限服务端凭据无法获得，停止云端调用，不以 `@cloudbase/js-sdk.callFunction` 的默认短等待替代。
- 远端 Python 函数当前已知配置为 90 秒/1024 MB；计划 worker 为 300 秒/512 MB，业务的 TC3 同步调用最多等待 290 秒。长音频包的既有审阅包将 Python 试验超时上限设为 210 秒，不能证明 290 秒业务调用已通过。因此必须先把调用/函数/客户端的真实时限和当前长音频证据核对一致，确定不会因请求超时而并行重算；本包不自行延长超时。
- 部署前重新只读记录环境、套餐剩余量/账单、函数列表与版本、执行超时/内存/异步配置、客户端调用规则、存储私有权限、集合/索引现状和精确回退包。任何费用不明、付费提示、权限扩大或旧函数改动超出本表即停止。
- 受控云端最多使用 5 个虚构账号、20 次合成音频请求；超出预算、需新增计费、需要生产/真实数据或须处理旧密钥时，应重新审阅范围。用户之后的质量测验不计入此云端施工预算，也不由开发实现冒充完成。
