## 当前本地证据与明确缺口

- `teacher-media/publish-gate.ts` 已在当前组织/目标班级、审核版本、版权证明、扫描、转码、题目/答案键/毫秒片段、字幕、连续播放能力均有效时冻结不可变媒体快照；证据顺序要求**原始上传先扫描→转码→转码产物再次扫描**，源扫描 SHA=转码输入 SHA、转码输出 SHA=最终扫描 SHA=媒体版本 SHA，时间/引擎/签名版本/报告与私有路径一致。未经扫描的原始文件不得先送入转码器。只有 `scanStatus=clean`、`transcodeStatus=ready` 两个字符串而无真实双扫描和转码证据记录时拒绝发布。学生投影仅含题干/选项/片段/字幕线索，不含答案键、解析或 `cloud://`。T-19/A-08 的审核提交、独立审核人通过/驳回、**通过后先待上架、另行上架**的事务仓库已本地测试。
- `task-media` 的会话与心跳按当前学员、任务、任务项、assignment/round、冻结媒体版本和学校时间校验，前跳与不合理速度拒绝，确认进度来自服务端 CAS/幂等收据。任务配音与自主 `student_works` 分库；任务作品在 `task_dubbing_works` 绑定任务项/轮次，封存文件/哈希为服务端私有字段。正式提交从会话、题目答案和作品封存导出证据，不信客户端自报进度。
- 本地虚构听力、视频和任务配音的发布→正式提交→教师评分/家长结果服务链均有自动测试；这是**无云端、无媒体播放器、无微信页面**的业务证据。T-08 人工语音评语已有受保护 begin/seal、当前提交绑定和正式反馈私有媒体引用本地契约；家长只读安全投影和短链由家长任务负责。
- `teacher_media_records` 的教师当前班级授权创建草稿、私有 stagingPath、幂等/CAS、待处理状态与 `sealProcessed` 受保护端口已有本地实现：**没有真实 processor 时返回 SERVICE_UNAVAILABLE**；虚构处理器注入的单测能走草稿→处理证据→独立审核→上架并原子写入 `learning_resources`。这只证明接口/状态链，不是实际扫描/转码。
- `review-query.getTaskMediaReviewEvidence` 已本地接 T-08 的指定正式提交/任务项：复用教师当前班级与提交版本授权，返回冻结题目、答案、毫秒片段、学生原答及服务端确认的观看证据；来源媒体与同轮次最终配音作品只签 60 秒地址，180 天到期/删除/错归属不签，访问记录操作审计。小程序云服务已有只读调用包装，**原 S-09/S-07 页面与非生产媒体文件尚未实测**。
- **尚缺**：教师原生 T-19/T-20 的上传、编辑、列表/预览与扫描/转码真实适配；A-08 页面和管理授予；教师在原学生页内只读播放/逐题判定；媒体文件真实逐项试听及版权审核；三类任务的微信页面/真机/弱网。真正的转码/病毒扫描执行器与费用、冷启动/超时尚未证明，媒体 gate 不得借已预处理素材自动声称“上传→扫描→转码”通过。本地单测中的 `virtual-unit-v1` 扫描/转码报告仅是纯虚构夹具，不对应任何非生产云端素材。

## 拟新增受保护数据与函数差异

新增集合均拟设 `ADMINONLY`，索引以 `workspace/m1-cloudbase/src/deployment/m3-teacher-database-manifest.ts` 为准，创建前逐项核当前环境无同名冲突：

| 集合 | 用途与关键索引 |
| --- | --- |
| `teacher_media_records` / `teacher_media_operations` | 教师媒体版本/审核状态/独立审核及幂等收据；`_id` 唯一、组织+创建人+状态查询。 |
| `task_media_sessions` / `task_media_operations` | 学员/任务项/轮次的连续播放确认与操作收据；`_id` 唯一、组织+学员+任务+项查询。 |
| `task_dubbing_works` / `task_dubbing_work_operations` | 课堂任务专用配音封存和行操作；`_id` 唯一、组织+学员+任务+项查询。 |
| `review_voice_drafts` / `review_voice_operations` | 教师当前提交专用语音草稿、封存、版本/幂等；`_id` 唯一、组织+教师+提交查询。 |

拟仅对既有 Node 函数做代码更新，不新建携带现行六项业务密钥的函数：`task-command`（媒体审核/上架及任务发布）、`student-task-query`（安全快照与媒体播放查询）、`learning-progress-command`（会话/心跳）、`submission-command`（正式证据）、`student-work-command`（任务配音独立封存）、`review-command`（教师语音评语与正式发布）、`review-query`（教师媒体只读证据及短链）；家长 `parent-query` 的媒体/反馈投影由家长任务单独审阅。`content-query` 的阅读音频按另一审阅包处理。最终函数名单、每只新/旧完整代码包 SHA、配置摘要和精确回退包须在本地功能冻结后填入，**当前不具备可批准的执行清单**。

新旧代码包均须含可用 `@cloudbase/node-sdk` 与媒体元数据依赖，不能将两文件源码包误当可运行包。CloudBase CLI 3.8.2 的 `fn code update` 可以显式使用单函数、无 `envVariables` 的 D 盘隔离配置，代码更新不改函数环境变量/路由；所有改动均先只读核当前代码 SHA/配置键名/版本路由，逐只更新与读回。禁用读取默认私有 `cloudbaserc.json` 的 `fn deploy`、禁将旧六密钥值装进新配置或新函数。完整包预计超 CLI 1.5 MB ZIP 限制，若用 SCF 平台临时 COS，须按 T-07/T-09 包同样核固定桶与账号 APPID 不同、实际桶归属和执行前后费用，不能仅凭推断称零费用。

## 最小虚构联调与退出用例

1. 林老师提交原创合成 MP3/AAC 与 MP4 草稿，受控封存记录真实 MIME、时长、字节、源 SHA、版权、班级范围与字幕/题目；源文件先扫描，只有干净且签名版本有效才进入隔离转码，输出文件重新计算 SHA 并再次扫描，全部证据与版本绑定。任一步失败、越界、换源版本及断点恢复分别阻断。**真实双扫描/转码实现与费用来源尚未确定，此项目前未通过。**
2. 获独立 `media.review` 管理授权且非上传者的虚构周老师在 A-08 逐题试听三题/三片段，核版权、扫描、转码、范围；通过→待上架，再确认上架，驳回必填原因。普通教师、上传者自审、跨班/跨组织、撤权旧会话、并发版本冲突均服务端拒绝并有审计。
3. T-18/T-06 只允许审核版本完整的媒体进入新任务快照；缺题干/答案键/主片段、0 或越界毫秒、字幕缺失、未审核/下架、无连续播放能力均拒绝。历史已发布任务继续用旧快照，学生详情不含答案键或私有路径。
4. 三类任务各以虚构学员完成：音频逐题原答与片段连续证据；视频累计有效区间≥90%和配套题；配音完整观看与当前任务项/轮次封存最终作品。前拖、伪造心跳、超速、跨学员/跨设备旧会话、重做沿用旧作品、重复操作及到期媒体均拒绝；服务端冻结正式提交版本。
5. T-08 从当前正式提交进入原 S-09/S-07 的教师只读内容主体，授权试听不追加学生播放进度，逐题判定/录音与人工评分仅按快照；语音评语须由当前教师封存并确认发布，AI 建议失败仍能发布人工文字/语音。G-03/G-05 只读本人孩子的正式反馈，媒体短链逐次重验绑定/任务/提交/反馈/180天学生原录音期限并审计。
