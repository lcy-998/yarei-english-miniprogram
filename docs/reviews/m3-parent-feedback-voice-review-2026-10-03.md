# M3 家长正式语音评语试听 B2 审阅准备（2026-10-03）

> **家长半链路本地已实现，教师封存/正式发布尚未交付；不申请云端授权。** 本切片消费教师主责冻结的 `ReviewFeedbackRecord.voiceComment` 私有记录。它与学生原始录音 B1、Vosk 试验、三类新媒体任务和已锁定的 A 批函数包分别验收，不能互代。

## 冻结的跨端合同

教师在有权提交及当前提交版本下完成语音评语录制、封存与正式确认；只有确认发布的反馈原子保存私有 `recordingId/fileId/durationMs/mediaVersion/sha256`。家长查询 `parent-query.getChildTask/getFeedback` 只返回 `voiceComment:{available:boolean,durationMs:number|null}`，不返回私有 ID、云路径或 URL。教师未发布、封存失败或媒体无效时按钮不出现；文字点评和分数继续按原版本可读。

家长点击 G-05 语音按钮时调用 `parent-query.getChildFeedbackVoicePlayback({childId,taskId,assignmentId,submissionVersion,feedbackId})`，客户端不传录音或文件 ID。服务端每次核对可信家长当前 `child.read` 绑定、同组织任务/作业关系、正式提交版本、当前反馈 ID 与已发布时间；仅从该已发布反馈读取私有媒体引用，短期签发约 60 秒 HTTPS 地址，成功签发留 `operation_logs` 审计。签发途中解绑再次拒绝，不把已生成地址返回家长。响应为 `{feedbackId,temporaryUrl,expiresAt,durationMs}`，没有私有 ID 或原始媒体哈希。G-05 用微信 `InnerAudioContext` 播放，离页/换版本即销毁上下文并作废在途查询；播放失败重新向服务端申请。

**保留期边界**：教师语音评语的独立媒体保留期尚未正式确定；本地服务只在教师发布记录明确可用且文件引用有效时签发，不自行套用学生原始录音的 180 天政策，也不生成虚构到期日。未来保留期确定后须在服务端停止签发和历史反馈投影中同步补规，已发布文字/分数仍保留。

## 本地专项与云端差异

家长本地虚构测试覆盖安全摘要、正常短链/审计、无语音、错反馈/提交版本、解绑及签发中途解绑、审计不含 URL/fileId；请求严格拒绝客户端额外 `fileId`。选择家长语音与函数入口专项运行，测试工具报告 3 文件/17 项通过，两侧 `typecheck` 与视觉静态检查通过。教师正式发布写入尚未落地，这些夹具仅验证家长消费边界。

B2 将在 B1/A 实际远端版本确定后更新 `parent-query` 的语音安全投影、新只读 action 与现有 `operation_logs` 成功试听审计写入；需读取正式 `review_feedback`、任务、作业、提交与当前绑定。没有新增集合或密钥，但短期签发读私有云文件；具体代码包/旧包哈希、配置不变、COS 零增费、虚构正式语音媒体和精确回退要在教师封存/正式发布函数冻结后另补，不能拿 A/B1 旧哈希申请授权。

## 人工验收前提

有权教师在虚构学生正式提交上完成文字或语音反馈发布，家长从 G-03/G-05 按当前/历史版本查看，试听同一版本；未发布、错版本、跨孩子、解绑、短地址过期、弱网、切后台均按预期拒绝/恢复，页面不泄露私有 ID。iOS/Android 真机各核对系统音频控制与横竖屏。教师端发布链、B2 非生产审阅和家长已登录页面未完成前，本项保持“本地合同通过，人工验收未测”。
