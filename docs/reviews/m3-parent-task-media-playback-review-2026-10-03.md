# M3 家长新媒体任务结果与回看 B3 审阅准备（2026-10-03）

> **本地安全投影和三类媒体回看接线已实现，尚无 B3 云端授权。** 三类媒体正式发布和提交目前只有虚构纯服务闭环，未通过 T-19/T-20/A-08 的人工审核、云端函数与已登录学生流程；家长不得把本地夹具当真实可见任务。A 批 D 盘冻结包不含 B3 字段或 action。

## 正式结果最小投影

`parent-query.getChildTask` 每次核对当前家长绑定和正式提交版本，只从冻结 `mediaSnapshot` 与服务端已核验的 `SubmissionAnswer` 得出：

- 听力：已核对播放片段数、逐题**本人原答**、客观判定/待教师评分；题干来自发布快照。
- 视频：服务端确认的连续有效观看时长/百分比及配套题原答与判定；观看空洞不能被页面上报替代。
- 任务配音：最终作品已提交和有效录音时长；**不返回** `finalWorkId` 或文件引用。

父级响应均不含 `mediaSessionId`、`mediaAssetKey`、`fileId`、`finalWorkId`、答案键、解析、内部播放心跳、字幕私有地址或试验 Vosk 分；损坏、未审核或版本不匹配的媒体快照 fail closed 显示“未记录/暂不可查看”。已发表老师反馈仍按同一正式提交版本显示；自动分只对完整审核的冻结媒体快照和服务端核验答案计算。

## 听力、视频与任务配音受控回看

本地新增 `parent-query.getTaskMediaPlayback({childId,taskId,assignmentId,submissionVersion,itemId})`。客户端不传媒体 ID/路径/会话。服务端逐次重验当前 `child.read` 绑定、任务对象、正式提交、任务项、审核版本与快照媒体 ID/版本一致性，且本次提交的服务端播放/题目证据须重新通过安全投影；只从冻结快照签约 60 秒 HTTPS 源地址。听力额外返回按已审核题目 `questionId` 对齐的 `startMs/endMs` 片段边界，**不返回答案键**；签发后再次核对绑定，成功写 `operation_logs` 家长只读回看审计。回看不新建学生媒体会话、不调用播放心跳，也不增加学生有效进度。G-03 听力用 `InnerAudioContext` 全段或逐题 `seek`/结束边界回听，视频用原生只读播放器；离页销毁音频并清除视频 URL/旧请求，地址失效重新申请。片段的实际起止、真机系统控制仍需已登录页面和设备验收。

任务配音只从正式提交答案的 `finalWorkId` 查独立 `task_dubbing_works`，不读 M2 自主 `student_works`，也不签教师原素材。服务端重验组织、孩子、任务、任务项、assignment、`round === submissionVersion`、审核媒体 ID/版本、封存状态、私有 `fileId`/哈希和答案记录的时长/大小；签发后重查作品与当前绑定，成功记审计。家长仅取得约 60 秒 HTTPS 试听地址，不取得作品 ID 或存储 ID；G-03 离页销毁音频。原件从**正式提交时刻**起满 180 天或 `mediaDeletedAt` 已标记时立即停签，历史提交与点评保留。当前媒体保留作业**尚未覆盖 `task_dubbing_works` 的物理到期清理**，因此此处仅能声明停签接线，不声称到期文件已删除或云端回放通过。
