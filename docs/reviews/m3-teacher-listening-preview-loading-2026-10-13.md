# 教师听力预览加载停滞排查与修正（2026-10-13）

## 现象与证据

教师端存在两条听力预览路径：T-18 内容选择进入 S-13 学生式只读预览，以及 T-19 素材库进入 T-20 素材预览。T-20 原实现将“音频已就绪”作为播放按钮前提，并在设置音频地址后才注册 `onCanplay`。如果就绪事件只在播放后触发，或在注册前已经发出，按钮会一直显示“正在加载音频”，用户无法主动启动播放。S-13 与 T-20 的云端预览调用原先均没有等待上限，网络请求若不结束，整页“正在加载素材”也不会退出。S-13 教师预览在会话变化时提前返回，原先没有清除加载态。

在既有非生产环境用虚构教师会话检查当前正式听力素材 `res_launch_sbc0008_listening_v2_20261013`：云端 `previewTeacherAsset` 约 1.94 秒返回，含 4 题和有效试听地址。修正前直接进入 S-13 与 T-20，当前素材均能正常载入，因此本次没有复现用户设备上具体素材的持续停滞；上述代码路径是确认存在的可导致无限等待的缺陷。修正后微信开发者工具模拟器中，T-20 初始 `audioReady=false` 时按钮显示“播放整段音频”且可点击；点击后页面进入播放状态，随后 `audioReady=true`。

修正后又从虚构教师 T-19 听力目录逐条进入其当前列出的 10 条素材：10/10 均退出整页加载态、无页面错误且拿到资产，单条页面打开约 3.4—3.5 秒。该结果覆盖当前目录的页面加载，不代表每条素材都已在真机上完成音频播放。

## 修正

- T-20 在设置音频地址之前注册事件；整段音频允许点击后主动启动播放，播放进度事件也可标记音频就绪。
- T-20 播放 12 秒没有进度时停止等待并显示刷新重试提示；隐藏、销毁、重载和播放结束时清理计时器。
- 教师素材预览服务在云端调用 20 秒仍未返回时给出可重试的网络错误；异常也返回可重试提示，使预览页面退出整页加载状态。
- S-13 和 T-20 在教师会话变化时清除加载态并提示重新进入，避免旧会话继续展示预览。

## 验证与边界

新增两组针对性测试，覆盖就绪事件在设置地址时同步触发、无就绪事件时主动播放和超时退出、云端请求永不返回时超时退出。`workspace npm run check` 通过：TypeScript 类型检查、视觉静态契约、327 个测试文件/1,412 项测试、历史网页后台 49 项测试及构建。微信开发者工具模拟器对上述当前听力素材的 T-20 页面进行了真实点击验证，加载与播放状态正常。

本次仅修改本地小程序前端，未上传体验版、提审或发布正式版本；用户实际设备和具体卡住素材尚待复现与真机点验。云端服务没有改动。
