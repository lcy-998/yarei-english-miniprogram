# 教师布置课堂任务加载恢复记录

日期：2026-10-22  
范围：教师 T-06 布置课堂任务页

## 现象与原因

页面初始化与内容目录回填会等待多个服务请求，但原实现没有统一捕获异步拒绝；会话失效时也直接返回而不关闭 `optionsLoading`。任一情况都会让表单控件持续禁用，表现为一直加载资源。

初始化还会串行读取授权学员分页以填充发布对象列表，这会增加等待时间；此项尚未改为按需分页。

## 修复

- T-06 初始化及目录内容回填增加异常收尾，失败后释放加载状态并保留错误提示。
- 无有效会话时明确结束加载并提示重新进入。
- 初始化失败且没有草稿选项时显示“重试加载”按钮。
- 保持已选目录 ID，回填请求失败后可再次进入并重试。

## 验证

- 定向页面测试：8/8 通过，包括服务拒绝和会话失效时加载状态复位。
- `npm run typecheck`：通过。
