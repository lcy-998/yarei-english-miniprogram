# M3 教学音视频资产来源纠正（2026-10-03）

用户明确：听力、看视频、任务配音的内容应与阅读书籍一样预先放入后台统一资产库，教师从授权目录选用；普通教师不上传、编辑或提交审核教学音视频。

0.63.0 权威基线已将链路改为：后台资产库导入和加工 → A-08 独立审核/上架及班级授权 → 教师 T-19/T-20 只读查找、预览、逐题试听 → T-18/T-06 选入任务 → 发布时服务端重验资产版本、授权和媒体规则。原先 T-19/T-20 的教师上传、编辑、改题目与改片段路径已撤回；资产下架仍不改历史任务快照。获管理授权的教师若在 A-08 操作，必须使用单独授予的管理功能权限，普通教学权限不随之扩大。

本轮把 `task-command` 中三项旧媒体审核/上架 action 改为拒绝，避免旧教师任务入口继续执行资产写入；原本未接入云函数的教师上传草稿服务保留为未部署的历史候选，不得按旧方案接线或部署。现有 T-19/T-20 视觉稿与教师上传审阅包、测试夹具也只保留历史属性，须按只读目录/预览及后台资产导入重新审阅。没有部署云函数、导入或改动云端素材，也没有宣称 M3 三类任务已经可发布。

后续实现须核对后台资产库与 CloudBase 内容记录的映射、资产导入者权限、独立审核、扫描转码费用、已审核听力题对位、教师按目标班级只读查询及发布时的二次校验。用虚构非生产数据验证普通教师无法写资产、已审内容可选择、下架/撤权被拦截、旧任务快照不变，再进行微信页面与真机验收。
