# M3 六页原生管理功能与操作体验核对（2026-10-07）

## 实际操作范围

在微信开发者工具模拟器中以非生产虚构教师会话进入 A-01/A-02/A-03/A-04/A-06/A-08；只执行读取、筛选和打开表单，没有提交管理写操作，也没有部署云函数或改动云端数据。运行结果保存于 `workspace/m3-acceptance/2026-10-07/admin-six-pages/render-check.json`；A-08 当前错误态截图为 `A-08-service-mismatch.png`。A-02/A-03 表单截图 `A-02-open-form.png`、`A-03-open-form.png` 是加入“列表未成功读取时禁止新建”保护之前的临时界面操作证据，不代表新增成功。

| 页面 | 模拟器结果 | 本轮可判断的体验 |
| --- | --- | --- |
| A-01 工作区 | 授权校验成功，状态为 `ready`，可进入六页路径 | 入口和返回区域可用；此页没有统计或写操作 |
| A-02 学校/班级 | 页面授权成功；学校资料及班级列表读取返回 `VALIDATION_ERROR` | 列表失败时继续打开新建班级会让教师填完才遇到服务错误，现已禁止盲目新建并给出重试入口；真实班级增改、教师分配及停用未能验收 |
| A-03 用户 | 页面授权成功；账号列表返回同类错误 | 新建账号、家长绑定现要求先成功读取列表；早前模拟器验证新建表单打开后可滚动定位，另一绑定表单不能同时覆盖当前输入；真实开户/设密、停用和解绑未能验收 |
| A-04 权限 | 页面授权成功；候选教师及授权列表读取返回同类错误 | 当前无法选择真实教师并验证授权保存、撤销和审计 |
| A-06 习题库 | 页面授权成功；题目列表读取返回同类错误 | 当前无法对真实题目验证预览、单条及批量上下架；通过临时模拟器虚构行点击，已上架题只出现“下架习题”，详情能定位但预览读取仍失败；没有执行写入 |
| A-08 音视频 | 页面授权成功；素材列表读取返回同类错误 | 模拟器实际点击“视频→全部类型”，筛选状态由 `video` 恢复为空；素材详情、短链预览、问题反馈与下架仍无真实记录可点 |

五个子页默认请求均返回同一类校验错误，而 A-01 的管理授权读取成功。当前六页云端审阅包仍标记为草稿且未获施工授权，现象与页面/服务版本不同步相符；尚不能仅凭客户端错误断定唯一根因。页面原先把错误说成“输入内容不符合要求”，容易使教师反复修改搜索条件。本轮只在默认读取遇到该错误时改为“管理服务与当前页面尚未同步，暂时无法读取；请联系维护人员”，不掩盖用户主动输入造成的其他错误。

## 已修的操作问题

- A-08“全部类型”按钮原传入 `all`，处理器只接受空值，点击后无法清除筛选；现已归一为空，并在模拟器真实点击及本地用例中验证。
- A-02/A-03/A-04/A-06 不再允许新表单覆盖未关闭的操作；尝试切换时提示先关闭当前操作。A-04 授权表单、A-06 题目预览与批量表单打开后自动定位，关闭或操作成功后返回列表位置。A-08 审计失败的“重试”改为单独重新读取审计，不重新打开并清空素材详情。
- A-06 已上架题目只显示“下架”，草稿或已下架题目只显示“上架”；预览读取失败可单独重试，且在题目详情不可读取时禁用单条上/下架，避免盲目操作。批量确认按钮明确写“确认上架”或“确认下架”。临时虚构行的模拟器截图为 `A-06-virtual-preview.png`，只证明页面动作和排版，不证明远端题目可读。
- A-04/A-06/A-08 的导航标题改为与 A-01—A-03 相同的左上角返回与标题行，六页内容边距统一。A-02/A-03 列表失败时禁用依赖该列表的新建操作，避免填写后才发现服务不可用。

## 尚未解决的体验缺口与后续验证

1. **云端读取阻断是首要问题。** 在现有 M3 六页非生产审阅包完成当前源码/制品/费用/回退复核并获得用户明确授权前，不执行部署。部署后须先逐页重测列表正常态，再用虚构数据执行创建、修改、授权、上下架、冲突、失败保留与审计闭环。
2. A-02 分配教师、A-03 绑定家长/学生与部分班级选择、A-04 指定班级授权仍要求手填账号或班级编号。仅靠文案无法把这些操作变直观；需要在各自权限范围内提供可选候选名单及服务端校验。当前跨权限候选数据契约未齐，本轮未擅自扩权或补造名单。
3. A-04“可授权教师”和“已有授权”两张列表可能出现同一教师；需要在真实列表可读取后核对是否合并或改为互斥筛选。A-08 仍缺跨校公共素材的来源学校与源版本投影；A-06 题型/标签与更新时间摘要也待数据契约补齐。
4. 当前模拟器截图只能证明错误态和局部表单交互。375×812、横屏、200% 字体、键盘、弱网和真机的主流程均未通过；A-08 旧批准稿仍与当前功能不一致，运行截图不能代替视觉批准。

本地验证：`npm run typecheck`、`npm run visual:check` 与原生管理页面定向测试已通过。整套 `npm run check` 中，314 个测试文件的 1318 项用例有 1316 项通过、2 项失败；失败仍为跟读评分失败重试的版本冲突，以及云函数部署模板比注册清单多出三个发音函数。因测试阶段失败，命令链未进入网页后台 `admin:check`。这些检查不能宣称六页业务功能验收通过。
