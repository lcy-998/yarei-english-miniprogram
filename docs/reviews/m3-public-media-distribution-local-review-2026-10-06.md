# M3 公共英语音视频本地分发审阅

状态：仅本地实现和验证；未创建索引、未导入或修改云端资源、未给真实账号赋权。

## 入口和范围

- 已加工的完整音视频候选由受控作业传入 `PublicMediaDistributionService.importVerified`。来源哈希、安全扫描、转码、版权资料、听力逐题片段和播放规则有缺项时，本地构建直接拒绝；记录标为非生产“待用户验收”，不标成人工审核通过。
- 公共源保存在审阅包指定的一所现有有效学校；其他学校使用隔离投影。不会为素材虚构一所学校，也不会把旧受限素材改成公共源。
- 入口脚本 `workspace/m1-cloudbase/tools/run-m3-public-media-distribution.mjs`：`plan <input.json>` 本地校验，不触云；`apply <input.json> <review.json>` 在审阅包授权后写入中央源并投影到当时所有有效学校；`sync-org <organizationId> <review.json>` 用于新学校创建或重新启用后的幂等增量同步。两个写入模式要求审阅文件明确非生产环境、操作、输入哈希或学校 ID，并再次核对环境未启用付费/超限计费。
- 审阅文件结构示例见 `docs/m1-cloudbase/templates/m3-public-media-review.example.json`；示例的 `approved` 默认为 `false`。新学校同步应使用 `operation: sync_new_organization` 和 `organizationId`，不使用导入输入摘要。
- 当前通用资产打包器明确拒绝独立音视频；须先由受控媒体处理作业生成完整输入。此脚本不上传文件、不生成扫描或转码证据，不应拿缺项素材绕过校验。
- 新学校创建/启用在当前 A-02 原生范围内未开放；将来实现该操作时，提交学校记录后调用 `syncOrganization`，失败保留可重试状态。现可用独立 `sync-org` 入口补齐，不得据此宣称自动触发已联调。

## 一致性

- 每校投影使用由中央源 ID 和学校 ID 算出的稳定资源 ID。重复导入、重复同步读取已有投影并核对来源，冲突时停止，不覆盖旧素材。
- 仅明确标记为公共、通过受控校验的新中央源允许投影；旧学校/班级受限资源不会因目录规则变化自动扩权。
- 管理者在任一学校下架公共素材时，同一事务将中央源置为已下架。教师目录列表、预览和任务资源读取会重新检查中央源状态，所以其余学校不能新布置。已发布任务保留原快照。

## 部署前核对

1. 在指定非生产环境核对现有索引，按 `docs/m1-cloudbase/templates/m3-public-media-indexes.fragment.json` 比对新增需求，避免重复创建等价索引。仅在新的 M3 审阅包授权后施工。
2. 核对 `learning_resources` 与 `operation_logs` 为服务端保护集合；检查媒体临时地址只在受保护查询后签发。
3. 冻结来源文件与处理记录哈希、输入 JSON 摘要、目标学校清单、费用/配额、回退方案，再运行 `plan`。审批文档应列明单次导入和新学校同步范围。
4. 受控执行后逐校核对源/投影内容版本、哈希、可布置目录、跨校普通教师只读预览、跨班教学权限拒绝、普通教师上传/修改/下架拒绝。
5. 在虚构数据上验证一校下架后其他学校立即不能新引用，旧任务仍可按快照查看；验证失败重试、重复执行、源缺失与版本冲突。

本地自动验证不替代 CloudBase 真实事务、索引、媒体播放和微信开发者工具/真机验收。
