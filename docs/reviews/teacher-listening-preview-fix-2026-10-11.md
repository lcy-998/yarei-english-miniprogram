# 教师布置听力预览修复（2026-10-11）

T-18 进入 S-13 的教师只读听力预览时，默认显示已有字幕；播放或拖动进度后，播放器上方以视频任务相同的字幕卡样式显示当前时间片段。教师批阅听力提交沿用同一显示方式。学生课堂听力仍固定开启磨耳朵，未播放区间的防快进规则不变。

共用 `media-player` 的进度条取消对原生滑块触控区域的裁剪，以便教师拖动定位。教师定位只更新本地预览播放位置和字幕，不调用学生播放心跳或作答写入。

验证：`workspace/` 的 `npm run check` 通过，包括小程序类型检查、视觉静态契约、318 个测试文件的 1352 项测试、历史网页后台 49 项测试及构建。新增回归核对教师拖动后的时间、字幕和音频起播位置。微信开发者工具实际触控与真机尚未执行。
