# S-13 听力任务独立页本地实现与验证

日期：2026-10-06。基线：0.69.0。阶段：M3 本地实现，未作微信页面或真机验收。

## 实现

- 学生从 S-09 点击整项听力任务进入独立 S-13；S-09 不再内嵌学生听力播放器和题卡，视频与配音入口保持原行为。
- S-13 同页展示连续播放进度、播放/暂停、五档倍速、磨耳朵、逐题片段、题干与选项。答案按学生会话、任务、分配关系、重做轮次、任务项和媒体版本保存本机；返回 S-09 后由原提交流程核对服务端播放和全部题目。
- 缓冲时播放器保留操作控件；12 秒无响应显示重试提示。音频错误或地址失效后重新建立播放上下文，进度同步失败保留相同操作 ID 的心跳供重试。未确认位置不可前跳。
- 顶部耳机插画以已批准 S-09 效果图为风格参考，用内置 ImageGen 生成透明 PNG，并登记到素材清单。S-13 完整页面主稿仍待视觉确认。
