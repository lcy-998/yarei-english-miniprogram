# 家长孩子任务筛选兼容修复（2026-10-25）

## 现象与定位

家长账号进入 G-03「孩子任务」时显示“输入内容不符合要求，请检查后重试”。该页没有文本输入；默认会向 `parent-query.listChildTasks` 发送近 30 天的 `startsOn`、`endsOn` 筛选。

在已核对的既有非生产 CloudBase 中，用用户提供的虚构家长账号登录并选择家长身份后，只读调用确认：

| 请求 | 结果 |
| --- | --- |
| 默认日期筛选 | `VALIDATION_ERROR`，`filters.endsOn: 不支持的字段。` |
| 日期加状态筛选 | 同上 |
| 旧版空筛选 | 成功，当前绑定孩子返回 0 条任务 |

因此是当前云函数尚未接受新版 G-03 筛选协议，并非家长填写内容错误。本轮没有读取、打印或保存密码、会话令牌、环境标识和个人数据。

## 修复

客户端先按现行协议请求。仅当云端明确返回新版筛选字段“不支持的字段”时，改用原有家长授权的空筛选接口逐页读取，并在本地按上海日期、状态及分页处理。每次最多读取 10 页、每页 100 条；超出上限时明确报服务版本未同步，不静默截断。其他校验错误继续原样返回。云端正常支持新协议后自动走现行服务端筛选，无需切换开关。未新增页面或扩大孩子读取权限。
