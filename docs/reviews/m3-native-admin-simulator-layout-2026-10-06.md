## 发现与修正

- A-05—A-08 状态筛选按钮受小程序按钮默认宽度影响，逐个占一行。共享管理样式现明确使用内容宽度和换行，窄屏下可并排显示。
- 模块右侧的“待接入”等状态沿用箭头的 22px 字号，挤压标题和说明。现改为 14px 状态文字，并增加说明行距。
- A-02 班级行的右侧操作区域挤压年级、学期和人数，导致信息拆成多行。现将班级信息与操作分行，按钮按内容宽度排列。
- A-02“新建班级”按钮样式过淡；单按钮表单的“确认保存”误被末项选择器标成橙色。现明确设置新建按钮样式，并仅将停用/下架操作标成橙色。
