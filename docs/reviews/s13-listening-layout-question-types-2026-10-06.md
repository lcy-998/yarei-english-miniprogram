# S-13 听力页背景、窄屏排版与题型展示修正

日期：2026-10-06。基线：0.70.1。范围：学生听力页和共用播放器的裸卡布局；没有修改云端题目、音频或已发布任务快照。

## 依据与修改

- 用户提供的 353×762 截图显示 S-13 浅绿底覆盖统一自然背景；播放器标题、不可快进标识、磨耳朵、播放与倍速和操作说明挤在窄行，说明文字成为竖列。截图中的《彼得兔》题目为文字作答，没有已发布选项。
- S-13 增加与 S-09 相同的自然背景图，并将播放器的标题与状态、时间轴、播放/倍速和提示分开排版；精简波形区与顶部插画尺寸。
- 题卡明确标记单选、多选、填空、问答。单选与多选使用整卡宽度的选项，支持单选替换、多选增删；填空与问答继续使用文字输入。缺失选项的选择题显示资源异常，不伪造选项。

## 验证

- 微信开发者工具 `compile_wxml` 对 S-13 成功；`simulator_open_page` 编译并打开页面。
- 在模拟器中仅注入虚构 UI 数据核对 353×762 竖屏：背景、播放器和单选题的最终截图分别为 `output/s13-listening-player-final-2026-10-06.png` 与 `output/s13-listening-choice-final-2026-10-06.png`。选项点击区完整占满题卡内容宽度，底部返回栏未遮挡当前题目；测试后恢复登录页。
- 单选、多选、填空和问答的呈现映射及多选增删、本机作答由本地测试覆盖。`npm run check` 通过：小程序 295 个测试文件/1225 项测试、视觉静态契约、历史后台 49 项测试与构建。
