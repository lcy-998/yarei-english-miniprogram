# 原生管理页必填错误提示布局复核（2026-10-21）

## 问题

A-02/A-03/A-04/A-06/A-08 的表单校验提示共用 `native-admin__notice`。多处使用微信 `<text>` 元素，但原样式没有设置块级布局；空字段提交后提示换行时，垂直边距不能稳定撑开后续控件，出现提示与输入框或按钮重叠。

## 修复

共用提示样式明确使用块级布局、盒模型、自动高度和长文字折行。提示放在卡片内时改用卡片内边距，不叠加页面级水平外边距；提示与操作按钮之间保留间距。所有使用该共用提示的管理页同步受益，未改变校验条件或写操作。

## 验证

- 微信开发者工具自动化在模拟器中打开 A-02 班级、A-03 新建账号、A-04 授权、A-06 题库，调用各自空值提交方法生成真实本地校验文案，并滚动到表单底部检查提示与按钮分离。
- A-08 反馈素材问题页因当前没有管理登录态，仅在开发者工具注入空值错误状态检查布局；未执行需要登录身份的提交方法。

- 类型与视觉静态检查结果以本次命令输出为准；真实账号操作和真机仍待验收。
