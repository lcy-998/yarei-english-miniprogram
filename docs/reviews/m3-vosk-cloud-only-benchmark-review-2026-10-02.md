## 为什么先在现有环境做这一窄阶段

**临时 COS 费用补充门槛**：本机 CLI 3.8.2 的 `cos` 上传实现使用 `GetTempCosInfo` 提供的临时授权和 CLI 内置的平台临时桶配置，上传对象路径含日期/账号/环境/函数名；上传后只清理本地 ZIP，未见远端删除。现有[CLI 部署文档](https://docs.cloudbase.net/cli-v1/functions/deploy)未说明该临时对象的保留期、是否计入用户 COS/CloudBase 配额或用户是否有删除权限；[SCF 计费说明](https://cloud.tencent.com/document/product/583/63306)只说明关联 COS 可能按产品规则另行计费，不能证明本平台临时桶免费。故**执行前必须从账单/平台配置取得本次临时上传及可能残留对象不会增加用户账单的核对证据**，并确认现有套餐可覆盖约 50 MB 代码上传/存留；若不能确认，就停在只读阶段，不上传、不部署。当前的 `EnvCharged=no`、超限按量关闭及函数计算余额只能覆盖既有环境计费状态，不能替代此项确认。

**2026-10-02 只读归属核对**：CLI 源码中临时桶后缀是平台固定 APPID；对当前账号的 `DescribeTcbAccountInfo.CloudAppId` 只在内存中做相等比较，结果为“不相等”，未输出任一标识值。[COS 桶名后缀代表所属账号](https://cloud.tencent.com/document/product/436/13312)，[跨账号上传后的对象仍归桶主账号](https://cloud.tencent.com/document/product/436/30749)，[COS 账单按桶显示在所属账号下](https://cloud.tencent.com/document/product/436/30747)。据此**推断**这只平台临时桶的存储/写请求不会进入当前用户 COS 账单；这不是腾讯云对 `GetTempCosInfo` 的逐项零费用承诺。若反事实地按当前账号标准存储计费，约 50 MB 存满一月以[0.118 元/GB/月](https://cloud.tencent.com/document/product/436/50201)估算约 **0.006 元**，少量写请求远低于 0.01 元，上传流量免费。执行当天仍须复核桶归属、CloudBase 套餐余额及 `EnvCharged=no`，每批查看账户 COS/CloudBase 账单；若出现本次归属不符或增费即停。

- 现有唯一非生产**个人版**环境的只读核验：`NORMAL`、`EnvCharged=no`、`EnableOverrun=false`，38/38 现行函数 `Active`。当前账期为 2026-09-12—10-12；套餐列云函数调用 20 万次/月、计算 15 万 GB·秒/月、出流量 4 GB、存储 3 GB。当前用量 API 返回 11,299 次调用、2,905,395,200 MB·ms（约 2,837 GB·秒）、函数流量 31 KB、存储 13 MB；据此算出的计算余额约 147,163 GB·秒。此环境属于既有个人版，`DescribeCreditsUsage` 返回的资源点扣减 0 不能替代旧配额用量。执行当天须重新只读核对，避免并行任务消耗改变余额。[CloudBase 配额指标单位](https://cloud.tencent.cn/document/product/876/42145)、[套餐查询](https://cloud.tencent.com/document/product/876/133103)。
- 本阶段**只新增一只内部函数**，当前 38 只低于 [单命名空间 50 只函数](https://cloud.tencent.com/document/product/583/11637)的默认数量限制。离线包 `D:\app-m3-cache\voice\pronunciation-inference-py311.zip` 为 49,907,445 字节、解压后 101,907,192 字节，SHA-256 `121cdf79624c678a52d1953831076c3c45198928688699b2e49f07dca0278e47`；253 个展开文件的逐项 SHA-256 清单保存在 D 盘同名 `.manifest.json`，清单 SHA-256 为 `0c1ee8495bbe80221e6e7f7273aebd98e85c043b67aedc64dddd4f7719d5d30f`。包低于官方 500 MB 解压上限。**本机 CloudBase CLI 3.8.2 的 `--deployMode zip` 路径另限 base64 ZIP 为 1.5 MB，不能用它上传此包；须用 CLI `--deployMode cos` 的临时 COS 代码包方式。**CLI 源码显示该模式先从指定函数目录重新压缩，再以 SCF `GetTempCosInfo` 返回的临时授权上传到平台临时 COS 路径（日期/账号/环境/函数名），用 `TempCosObjectName` 创建函数；该临时对象不等同于本项目的私有学生存储前缀。CLI 只在上传后清理**本地**压缩文件，未见远端删除动作；官方文档也未承诺临时对象清理时间，因此按可能持续占约 50 MB、产生一次上传流量核算，不承诺零残留。[官方 CLI 部署模式](https://docs.cloudbase.net/cli-v1/functions/deploy)。模型、wheel 版本/哈希见 `workspace/m1-cloudbase/voice-inference/dependencies.lock.json`。
- 本函数仅注入**新生成、仅供此试验的** `VOICE_INTERNAL_SECRET`、`VOICE_ALLOWED_MEDIA_HOST`、`VOICE_MEDIA_DOWNLOAD_TIMEOUT_SEC`、`VOICE_MODEL_PATH`、`VOICE_BENCHMARK_LOG=1`；绝不注入或读取现有六项 `YAREI_*` 业务密钥，不部署 `pronunciation-command` / `pronunciation-query`，不读取账号、组织、任务或提交集合。用户此前决定六项旧密钥暂不轮换，保持现状。

## 具体操作与数据边界

1. **再次只读预检**：核对环境唯一性、套餐/余额、函数名称未占用、Python3.11 普通函数可用、CLI 管理权限、完整环境级函数安全规则及私有存储规则。只记录环境配置哈希、字段名和计数，不输出环境 ID、密钥或完整规则内容。
   - 本轮已通过只读 `DescribeStorageSafeRule` 核对既有唯一云存储桶 `AclTag=PRIVATE`、无自定义规则；实施前仍重查，不把 CLI 已废弃的 `storage get-acl` 文本结果当权限证据。
2. **先保护调用入口**：当前只读规则查询为 `CUSTOM`，现有键仅 `*`（已登录、非匿名）和 `maintenance-timer: invoke:false`，没有语音函数例外。执行时把现行环境级函数安全规则完整备份并只新增 `pronunciation-inference: { invoke: false }`，回读确认其他两项及任何新例外保持不变；规则可在函数部署前设置已有 M2 实操证据。该规则拒绝客户端直调，管理端 API 仍可调用，函数内 HMAC 再校验。若平台不能先设置拒绝规则，停止部署。[CloudBase 函数安全规则适用范围](https://docs.cloudbase.net/cloud-function/security-rules)。
3. **单函数部署**：仅创建 `pronunciation-inference` Python3.11 普通事件函数，测试配置候选 **1024 MB、单次 90 秒、私有文件下载最多 30 秒**；这些数字只为限量云端测量，不是学生端正式等待或评分验收值。待批准的不可直接部署配置片段在 `docs/m3-vosk-cloud-benchmark-function.fragment.json`。授权后将已锁定的 ZIP 解压到 D 盘只含该函数的新暂存目录，生成**仅列该函数、无旧 38 函数/六旧密钥**的临时 cloudbaserc；命令形态为 `node <CloudBase-CLI> --config-file <D盘隔离配置> fn deploy pronunciation-inference --dir <D盘函数目录> --deployMode cos --runtime Python3.11 --install-dependency false --json`（实际环境 ID 只在受限配置中，绝不写进本文）。禁止 `--all`、`--force`、默认项目配置或 `--deployMode zip`。部署权限至少包括新函数创建/配置、环境级规则增量、SCF 临时 COS 代码上传与后续管理端 Invoke/日志读取；临时角色只检查是否具备权限，不申请更高权限或开付费。离线 ZIP 根目录含 `main.py`；不在线下载模型、不开预置并发、不切云托管、不创建触发器、数据库集合或小程序入口。部署后只读下载该**新函数**代码到 D 盘，逐项比对 `main.py`、`inference.py`、模型文件和依赖 wheel 展开的哈希/清单、`Active`、运行配置、客户端直调拒绝与无签名管理调用拒绝；CLI 重新压缩可使云端整包 ZIP 哈希不同于本地预制 ZIP，故不能只比整包哈希。
   - **已知上传故障**：M2 在同一环境多次出现默认临时 COS 域名 DNS 解析失败，曾回退到小 ZIP 直传；本包约 50 MB，CLI 直传 1.5 MB 路径不可用。COS 域名再次解析或上传失败时只核对新函数未被错误创建/更新、规则仍禁调和本次临时对象状态，然后停止；不得改镜像、云托管、控制台未审路径、付费网络或调用旧业务函数来绕过。
4. **原创合成音频**：仅将此前 M2 虚构验收包的原创英语合成短句及本地由同一合成音频生成的 1 秒、静音、噪声与约 299 秒 MP3 上传到全新私有前缀 `m3-voice-benchmark/2026-10-02/`，最多 5 个文件、合计不超过 8 MB；不复用学生录音、M1/M2 存储路径或真实儿童声音。执行前再次核对云存储仍为 `PRIVATE`；使用现有 CLI 的 `storage upload` 与 `storage url` 取得短期目标 URL，**捕获到受限测试过程而不在终端/日志打印**。Python 再核对允许域名、大小、SHA-256、MP3 格式和时长；URL、令牌及完整识别文本不落日志。
5. **管理端限量调用**：用当前 CLI 的临时管理凭据调用 SCF `Invoke`，传 `InvocationType=Event`、正确地域/命名空间、仅包含短期 URL/预期哈希的**签名**事件，最多 **20 次**。该 API 异步返回请求 ID，避开 CloudBase JS SDK 函数间 `callFunction` 默认约 15 秒的等待上限；[官方说明](https://docs.cloudbase.net/en/cloud-function/faq)、[SCF Invoke 参数](https://cloud.tencent.com/document/product/583/17243)。`VOICE_BENCHMARK_LOG=1` 时 Python **仅向管理端回时长、识别词数、耗时、模型版本或错误摘要**，不返回词列表/转写；日志同样只记该摘要。通过只读 `GetRequestStatus` 和该请求 ID 的受控函数日志读取平台冷启动/执行时长、内存与错误。先 1 秒和短句各一冷一热，成功后再跑噪声与 299 秒；每种长音频最多 5 次。若 Event 调用/日志无法对账，停止，不改用未验证的同步 SDK 长等待。
6. **额度前后对账与固定收尾**：每批核对调用、计算 GB·秒、存储和流量变化。全部试验最坏按 20 次×1 GB×90 秒为 **1,800 GB·秒**，占预检计算余额约 1.3%；新增调用最多 20 次，私有媒体下载按 20×20 MB 的极端上界为 400 MB（实际虚构包应远低于此），另计约 50 MB 的一次平台临时代码包 COS 上传及可能残留存储。如近余额/异常费用提示，立即停止。完成后**保留**新内部函数供审计，但从该函数配置中移除新 `VOICE_INTERNAL_SECRET` 和 `VOICE_BENCHMARK_LOG`，使管理端无签名也无法再运行；保留 `invoke:false` 和无触发器。逐一按精确文件 ID/哈希删除本包在 `m3-voice-benchmark/2026-10-02/` 新建的最多 5 个合成文件，并记录删除结果；不使用前缀通配删除。CLI 临时 COS 对象在不同 APPID 的平台桶下，**不尝试以当前账号删除平台对象**；执行记录只保留该次对象标识、约 50 MB 的潜在残留及账单跟踪，平台生命周期仍需后续核对。旧 38 函数、M1/M2 数据与六项旧密钥不动。

## 回退、停止与验收边界

- 任何部署前 `invoke:false` 无法确认、无签名/客户端直调未被拒绝、原函数规则变化、包/模型哈希不符、临时代码包上传权限不足、费用/额度风险、临时 URL 越域、Python native 库无法加载、90 秒测试上限不足或冷/热结果无法对账，立即停止后续调用。保留新函数的 `invoke:false`、清除新内部密钥与日志开关、保持无触发器；只按精确 ID 清理本包创建的合成对象，不恢复使函数可被客户端调用的旧通配规则，不尝试删除不同 APPID 的平台临时对象，也不清理其他文件。
- 本阶段成功只说明 **CloudBase Linux 目标能离线运行该模型且测得资源/时延**。下一阶段是否允许学生接线，仍须另审 Node→Python 的 SDK 等待或真正异步作业、可信授权/版本/审计、低置信度与五次有效上限、明确的用户可见最终等待上限和人工儿童朗读质量对照。试验分不得进入正式任务或打卡。
- 按 `AGENTS.md`，这是 M3 新云端变更；现有 M2 授权不覆盖。只有用户针对**本具体包**明确同意现有非生产环境、全新函数/私有合成文件/规则增量、CLI 临时 COS 代码上传、至多 20 次与上述费用/回退范围后，且执行前已核对**不会新增用户账单**，才可实施。若临时 COS 计费归属仍无法确认、任一动作超出包或需要付费，须停止并另审，不以用户同意测试推定同意付费。
