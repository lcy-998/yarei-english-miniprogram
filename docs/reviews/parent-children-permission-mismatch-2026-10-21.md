# 家长孩子页误报无权限修复记录（2026-10-21）

## 现象与原因

家长首页可显示已绑定孩子，G-02“孩子管理”却显示“无权查看孩子信息”。首页从当前 `app-service.listParentChildren` 读取绑定关系，G-02 从分包内独立的旧 `m1-app-service` 实例读取；后者默认使用内存演示仓库，没有使用启动时配置的 CloudBase 仓库，因此把真实登录的虚构家长账号误判为无权限。

## 改动

- G-02 的列表、绑定和解绑统一使用首页所在的 `app-service`，由相同的 CloudBase 会话和服务端关系权限决定结果。
- 切换孩子时从已加载的绑定列表确认目标，再更新会话中的当前孩子并返回首页。
- 保留服务端的 `child.read`、本人绑定关系和版本校验；没有修改云端权限或数据。

## 验证

- 家长页面回归测试覆盖首页与 G-02 使用同一列表接口、孩子切换和刷新失败时保留列表。
- 本地 `npm run typecheck` 通过；家长页面定向测试 6/6 通过；`npm run visual:check` 通过。
- `npm run check` 中全量业务测试出现与本次页面改动无关的后端失败：种子分批协调器 2 项、CloudBase 部署引导 1 项、函数日志静态门禁 1 项；该命令未通过，发现失败后中止了长时间运行的后续测试，不能报告完整项目检查通过。
- 微信开发者工具已打开工程；自动化连接超时，尚无已登录家长页面的开发者工具操作验收。需要用虚构家长账号确认“首页 → 孩子 → 切换 → 解绑”流程。
