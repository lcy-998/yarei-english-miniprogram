2. **仅一只函数的代码更新**：以 D 盘隔离目录和只含 `pronunciation-inference` 的配置，用 CloudBase CLI `fn code update ... --deployMode cos` 上传上述固定包。CLI 的直接 ZIP 上传上限不足约 50 MB，故本包明确包含**第三次**约 50 MB 的平台临时 COS 上传，不使用 `--all`、镜像、云托管或其他未审方式。更新后只读下载这只函数代码，对照 253/253 文件哈希；不一致即停，不注入测试密钥。旧 38 只函数及客户端规则不改。
3. **临时配置**：只对这只内部函数注入本轮新生成的短期 `VOICE_INTERNAL_SECRET`、`VOICE_ALLOWED_MEDIA_HOST`、`VOICE_MEDIA_DOWNLOAD_TIMEOUT_SEC=30`、`VOICE_BENCHMARK_LOG=1`，不设置 `VOICE_MODEL_PATH`；临时将函数执行超时从 90 秒调至 **210 秒**，内存保持 **1024 MB**，不启用预置并发、付费预热或异步执行。执行前读回初始化上限，须不超过 65 秒；两者相加最多 275 秒，为 [同步 Invoke 的 300 秒接口等待上限](https://cloud.tencent.cn/document/product/583/17243)留至少 25 秒余量，亦低于 [SCF 函数 900 秒配置上限](https://cloud.tencent.com/document/product/583/11637)。管理端请求用已经本地模拟确认的 .NET `HttpClient`，`Timeout=290s`、禁重定向、不加重试处理器；执行前审查实际请求脚本与读回值，任何一项无法证明即不发请求。210 秒是**测试上限**，不作为学生最终等待上限。
4. **私有媒体**：只把上述两份样本上传新前缀 `m3-voice-long-perf/2026-10-03/` 下两个预定精确文件 ID；云端读回各自 SHA-256、长度和私有权限后才调用。每次请求临发前按 [CloudBase 临时 URL 的 `maxAge` 参数](https://docs.cloudbase.net/api-reference/manager/node/storage)签发 **360 秒**有效期，调用脚本严格解析 [COS URL 的 `q-sign-time` 起止秒数](https://cloud.tencent.com/document/product/436/68284)，要求有效期≤360秒、剩余≥275秒，签发到发起调用不超过30秒；结合初始化≤65秒，进入函数下载时理论剩余≥210秒。若实际 CloudBase URL 没有可核验的 `q-sign-time`、时钟/签发时间不能对上或有效期不足，即停在预检；不能通过延长私有对象公开期绕过。HMAC 事件仍受60秒时间窗口约束，若平台初始化导致签名失效，判该调用失败并停止，不放宽鉴权。签名事件只含必要文件临时地址和摘要，地址/签名只保留在 D 盘受限临时区，不入仓库或日志。单样本约 2.4 MB，仍在项目录音 20 MB/5 分钟边界内。

## 额度上限、停止与固定清理

- 函数侧最多 **4 次主动调用 × 1 GB × 210 秒 = 840 GB·秒**，约为现有 150,000 GB·秒月套餐额度的 **0.56%**；这是保守的函数计算预算，不是实际费用承诺。两份私有样本合计 **2,401,175 字节**，再加两次读回及日志查询；另有一次约 50 MB 的平台临时 COS 代码上传。前一轮结束时环境月用量约 2,913 GB·秒，实际执行前仍须重新读取余量和费用状态。超限按量继续关闭，任何付费提示、不可解释调用增长或账单新增即停。
- 若平台 API/客户端在 210 秒附近提前断连、超时、产生无法核对的额外执行，或 5 分钟样本超过 210 秒，则判本配置下**未通过**，不在本包内继续提高到 300/900 秒、扩大内存、切换异步、自动重试或调整模型；另提可审阅方案。少量两次样本只给观察值，**不能**计算有意义的 P95、冻结学生等待上限或证明规模化容量。
- 无论成功或失败，先停止调用，清除这只函数本轮所有用户环境变量，并将执行超时恢复到读回的原值 **90 秒**；确认 `invoke:false`、触发器 0、原 38 只 `Active`。只对本轮两个预定样本逐个精确 dry-run 后按文件 ID 删除，查前缀为空；不使用通配或递归删除，不触碰 M1/M2 媒体或数据。本地短期密钥、签名事件、临时 URL 按精确路径清理。保留内部函数禁调代码和无秘密的审计记录。若配置清理失败，停止进一步测试并立即按受控回退追踪，不把“已发出清理命令”写成“已清理”。
