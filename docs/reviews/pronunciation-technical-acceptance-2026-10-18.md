# 跟读评分技术验收记录（2026-10-18）

## 验收结论

**部分通过；完整功能验收未通过。** 已验证受控非生产 CloudBase 的内部 Vosk 推理和评分规则链路，以及本地异步作业、页面状态、失败恢复等合约。低音量和加噪合成样本仍获得分数；没有合规儿童朗读与人工评分对照、当前登录学生页面端到端、当前轮 CloudBase 入库/学生可见及规定的冷/热启动分段时延证据。不得据此开放正式评分或把试验分计入任务成绩、打卡或家长正式报告。

## 环境与样本

- 目标为既有非生产 CloudBase。只读预检确认环境 `NORMAL`、个人版、未付费、未开超额计费；当期费用读数为 0，函数调用配额读数 3,529（低于既定 190,000 停止线），存储 ACL 为私有。`pronunciation-command`、`pronunciation-query`、`pronunciation-worker`、`pronunciation-inference` 均为 `Active`。
- 使用归档虚构合成音频包 `m3-pronunciation-technical-synthetic-v1`，四条样本的本地 SHA-256 与版本清单逐条吻合。样本仅作技术传输/解码/低置信度异常检查，不含儿童录音。
- 使用服务端 HMAC 签名直接调用内部 `pronunciation-inference`；未创建学生录音记录或作业记录，也未读取、保存或输出识别转写。每个上传到唯一私有测试前缀的临时文件均已删除；精确清理回执 4/4，前缀读回 0 个剩余对象。

## 未通过项与限制

1. 需要经许可的儿童朗读样本、人工盲评对照及适龄/设备/噪声条件覆盖，才能判定评分质量；本轮没有使用真实儿童录音。
2. 未用已登录学生页面重新完成录音、上传、离页异步评分、稍后查看/失败重试的闭环；上次完整服务闭环证据仍是 2026-10-17 的单条 2.011 秒合成朗读，耗时 9.452 秒。
3. 未记录冷启动、热启动、私有录音读取、解码、推理、落库各阶段与学生可见等待时长，未冻结单次执行/最终等待上限。
4. 低音量和加噪技术样本返回高试验分，当前无法据此声称已具备可靠噪声或音量判定能力。

Vosk 结果继续保持试验性；本记录不是儿童语音质量验收，也不是生产评分准入。
