# M3 四任务并行施工边界（2026-10-02）

> 用户要求学生端、家长端、教师端及语音评分验证部署四个独立任务并行启动。M2 已由用户于 2026-10-02 接收；当前统一产品基线 0.62.0，M3 开发中。本文件只记录并行工作边界，不代表 M3 云端授权、收费许可或功能验收。

## 工作区与磁盘

- 四个 Codex 任务直接使用 `D:\app` 这一已保存项目，不创建默认位于 C 盘的托管 Git 工作树；所有任务看到同一工作树，必须保留其他任务及用户的未提交改动。
- 大模型、Python 虚拟环境、下载和构建缓存放入 `D:\app-m3-cache` 下各任务独立目录，禁止放进小程序包、Git 仓库或 C 盘默认缓存。命令执行前按需设置临时目录、包缓存和模型缓存环境变量。D 盘启动时约剩余 4.2 GB；下载/构建前核对剩余容量，空间不足时暂停并报告。
- 不切换或重置共享 Git 分支，不做全仓格式化、清理或提交。模型制品先固定来源、许可与 SHA-256，再限量获取；不重复下载。
