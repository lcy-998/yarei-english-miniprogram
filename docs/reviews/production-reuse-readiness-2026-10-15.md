## 执行顺序与放行门槛

1. **冻结可发布版本。** 在保留当前共享工作树修改的前提下确定唯一源码提交、云函数版本和小程序包；完成主项目与 CloudBase 检查、微信开发者工具完整编译。未冻结的 829 项工作树变更不能直接作为可重复部署包。
2. **做精确数据清单。** 只读导出组织、用户/身份、任务/提交/点评、素材源/组织投影、存储对象、定时器、审计与索引的数量和目标 ID；按真实可用、虚构测试、受限/缺项、历史保留分类。列出每条拟停用或隔离的 ID、引用、旧任务影响与回退方法；不批量删除或重写历史。
3. **建立同环境回退点。** 在任何生产用途切换前取得可验证的数据库、存储、云函数代码/配置及小程序版本备份，校验恢复范围、权限与完成时间。由于仅有一个环境，回退不能假设可切到另一套 CloudBase；至少演练代码回退及小范围数据恢复。
4. **固定正式环境连接。** 为正式构建提供明确且可审计的目标环境绑定，生产启动失败时阻止业务读写并显示可恢复错误，不得静默进入内存模式。保留 M0 内存 repository 用于明确的本地演示路径。对缺配置、SDK 初始化失败、断网、旧会话做页面及服务端验证。
5. **清理与隔离虚构主体。** 逐账号停用或隔离演示登录，撤销测试管理授权和会话；对测试素材、测试任务、候补内容做引用感知的软下架或隔离，保留审计和历史快照。任何真实学生账号导入前验证组织归属、最小权限、家长绑定和未成年人数据处理规则。
6. **补齐 M3/M4 验收。** 完成当前 P0 功能、原生六页、批量导入、媒体/AI 边界与已接受遗留项的适用证据；在 iOS/Android 真机做主闭环、横竖屏、弱网、权限撤销；完成安全、隐私、性能、监控告警、备份/回滚演练与提审资料。AI 试验分保持与正式成绩隔离，教师建议不得自动发布。
7. **上线切换。** 前述证据及费用/配额核对通过后，再确定切换窗口、只读基线、值守人、失败阈值和回退触发条件；按独立门禁处理真实账号授权、生产基础设施/密钥、付费及小程序体验版上传、提审和正式发布。切换后用最小真实授权路径读回，核对监控和审计，不用真实儿童数据做探针。

## 当前不能放行的具体原因

- M3/M4 尚未达到权威文档退出条件；原生管理、真机、弱网及安全/隐私等证据缺失。
- 正式小程序环境绑定仍是开发用本地文件/本机存储，且云初始化失败会静默使用内存数据。
- 同一环境保留虚构测试账号、历史测试数据与不同审核状态内容，尚无逐 ID 的生产隔离和已演练的完整回退清单。
- 当前环境是个人版且关闭超额计费，尚无真实使用容量、配额与费用边界决定。

因此本次没有执行任何云端写入或正式小程序发布动作。下一步先完成第 1—4 项的可审阅材料与安全实现，再进行受控切换。
