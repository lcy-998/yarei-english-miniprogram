# M3 Qwen 教师建议云端静态可行性审阅包（草案，2026-10-02）

> 当前判定：**只读审阅，暂不创建或部署函数。** 0.62.0 基线要求 Qwen 模型加载、推理、冷/热启动及质量试验仅在受控 CloudBase 云端进行；本机只核对模型来源、许可、SHA-256、接口与包体。此包是 T-08 建议能力的独立技术试验，不接 T-08 正式入口，不发布点评，也不更改 M1/M2 业务数据。四任务分派和本包草案均不是 M3 云端或付费授权。

## 目标与范围

- **唯一目标**：判断 Qwen3-0.6B Q4_0 + Linux 目标 CPU 推理程序能否在现有非生产 CloudBase **普通云函数**的包体、内存、时延及现有额度内，以虚构作业摘要生成可供教师评审的中文建议。失败即停止该试验，不自动改用云托管、镜像函数或外部 AI 供应商。
- **目标环境**：现有已核对的非生产环境；执行前由有权操作者只读确认环境身份、地域、套餐、函数数目、实际剩余资源点、EnableOverrun、代码包与内存/超时限制。审阅包不保存环境 ID、账号或凭据。生产环境、真实儿童数据、真实教材、真实媒体及正式提审均不在范围内。
- **模型制品**：官方 [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B) 与 [ggml-org Q4_0 GGUF](https://huggingface.co/ggml-org/Qwen3-0.6B-GGUF/blob/main/Qwen3-0.6B-Q4_0.gguf) 均标 Apache-2.0。候选 GGUF 为 428,970,080 字节，发布 SHA-256 `da2572f16c06133561ce56accaa822216f2391ef4d37fba427801cd6736417d4`；本机 D 盘缓存的同名文件已算得相同摘要。模型不进 Git 仓库、小程序包、业务函数包或 C 盘缓存。项目负责人仍须确认许可适用范围。
- **静态包门槛**：腾讯云[配额说明](https://cloud.tencent.com/document/product/583/11637)列出单版本代码加层**压缩前**合计 500 MB 上限；[部署选型](https://cloud.tencent.com/document/product/583/73923)列出直接 ZIP 上传 50 MB、文件夹 250 MB，较大包须走 COS。下节已取得 Linux 推理程序的许可、清单、解包字节数与哈希，目标 CloudBase 实际版本限制、运行库与费用仍须核对。只要超限、部署方式要求新增付费或包内不可复核，立即停下，不通过拆到运行时公网下载来规避限制。

### 2026-10-03 Linux 目标制品静态核对（未运行）

- 固定 [llama.cpp `b11345` 官方发布](https://github.com/ggml-org/llama.cpp/releases/tag/b11345)中的 Ubuntu x64 CPU `llama-b11345-bin-ubuntu-x64.tar.gz`，GitHub 发布资产记录大小 **17,551,918 字节**、SHA-256 `9f4e4242818a0528b6771c338d11513b06f72d6d325a616ba07fc172799c2a9e`；D 盘实际下载文件的大小与 SHA 均一致。归档内 `LICENSE` 为 MIT；`llama-cli` 及 Linux `libggml-*` 仅做文件清单、哈希和 ELF 依赖读取，**没有在本机执行模型或 Linux 程序**。
- 归档 50 个常规文件解包字节数合计 **45,388,206**，10 个相对链接指向归档内同目录库。模型 GGUF **428,970,080** 字节 + 这批文件 = **474,358,286** 字节；以较严格的十进制 500,000,000 字节核对，尚余 **25,641,714** 字节供最小包装/配置。这个余量未计服务运行库与函数自身代码，故只能判为“静态可能装入”，不能判为目标普通函数可部署。Windows 解包时 10 个 Linux 相对软链接未能创建，云端制品须从原始校验通过的 tar 在 Linux 目标打包时保留链接；D 盘解压目录不是可直接部署包。
- 对官方 `llama-cli` 的 ELF 静态依赖检查显示 `libllama-cli-impl.so`、`libssl.so.3`、`libcrypto.so.3`、`libstdc++.so.6`、`libgcc_s.so.1`、`libc.so.6` 和加载器；发布归档**不含** OpenSSL 与 C++ 运行库。现有 CloudBase 目标 Node.js 运行时是否具备 ABI 兼容的这些库尚无云端证据。后续独立云端包先在受控函数读取目标运行时库/架构/内存配置，再决定是否需加入经许可核对的库；加入后仍须复算 500 MB 余量及 COS 上传费用。无法满足时按本包停止条件结束普通函数试验，另审云托管或更小制品候选，不能借本机静态清单宣称 Qwen 建议通过。

## 拟建的最小云端边界（未执行）

1. **仅一个新函数**：暂名 `teacher-suggestion-inference-trial`，采用与现有业务函数隔离的普通云函数版本。安全规则合并现有环境级规则后，对小程序客户端设 `invoke:false`；无 HTTP 公开路由、无定时触发器、无数据库/云存储业务读写权限。试验函数不调用 `review-query`、`review-command` 或任何现有 M1/M2 函数。
2. **全新独立试验密钥**：如实际调用路径需内部鉴别，由有权限者仅在该函数与受控操作端创建全新的 `QWEN_TRIAL_INTERNAL_SECRET`，限定本试验，带请求时间窗、操作 ID、摘要与次数限制。**不读取、不轮换、不注入当前六项非生产业务密钥**；不把密钥值写进命令、文档、日志或仓库。现有密钥风险与用户要求维持账号、旧绑定码和预览现状的决定不因本试验而解除。
3. **输入**：冻结的虚构任务/作答事实摘要 100 例，预先去除姓名、手机号、学号、录音、开放文本和组织标识；样本由本地纯规则生成并在审阅时逐项列摘要/哈希。每次请求只携带最小事实、`modelVersion`、`promptVersion`、试验操作 ID，不上传真实提交，也不让模型读取业务库。
4. **输出**：只返回建议候选、引用事实 ID、耗时、模型/提示词版本和技术错误码；不存为正式点评或成绩，不推送学生/家长。保留必要的聚合审计（请求哈希、成功/拒绝、耗时、版本、资源用量），不记录原始作答、模型完整输入或可能含个人信息的输出正文。
5. **限量顺序**：先空载启动/版本与 SHA 核验，再最多 5 次冷/热短请求核对内存和错误；安全与费用仍正常后最多 20 次虚构样本试验；扩大至 100 例教师双评前再审额度。当前只提出上限，**不授权调用**。任何新增函数配置、存储对象、COS 上传、调用或安全规则发布须在最终审阅包写明精确差异、费用上界和回退后获一次明确授权。

## 费用、性能与质量停止条件

- 执行前记录本计费周期函数调用/计算、COS 存储/上传/下载与出流量剩余额度及试验上界。EnableOverrun 保持关闭；若控制台提示购买、升配、开启超限按量或预计产生未批准费用，停止并另行由用户决定。CloudBase [云托管按量计费](https://docs.cloudbase.net/run/introduction)且当前方案不自动进入该产品。
- 普通函数的 CPU 随内存配置变化，最大内存与超时以目标环境实测为准；腾讯云当前公开[函数配置](https://docs.cloudbase.net/cloud-function/function-configuration/config)给出普通函数 64—3072 MB、1—900 秒的范围。这不是候选模型可在该环境运行的证明。必须记录冷/热启动、峰值内存、生成耗时、单次资源点和失败率，再由产品负责人冻结体验阈值。
- 100 例虚构作业由至少两名教师独立评审事实准确、语气、儿童适切性和可采纳性。未通过事实/质量、包体、越权、调用时限或零新增费用门槛时，T-08 继续人工点评，Qwen 切片标未通过；规则化常用评语不得冒称 AI。

## 回退与未完成核对

- 部署前保存环境级安全规则完整快照、目标函数/名称冲突核对、套餐与额度读数；不得批量重发当前业务函数。若试验失败，先使试验函数不可调用并停止限量操作，保留摘要审计，按审阅包列明的函数/模型对象做精确回退；不动既有任务、提交、反馈和六项密钥。
