# TCH-001 学员批量 CSV 本地计划

> 范围：M1 纯本地解析、校验、错误结果和筛选导出。本文不授权创建 CloudBase Auth 账号、写数据库、导入云端或处理真实个人信息。

## 1. 导入模板

文件必须为严格 UTF-8，可带 UTF-8 BOM，固定表头和顺序为：

```text
student_number,display_name,mobile,class_id
```

模板约束：

- 文件最大 1 MB，单次最多 500 个数据行。
- `student_number` 必填，最多 64 个字符，只允许英文字母、数字、下划线和连字符，首字符必须为字母或数字；比较时忽略英文大小写。
- `display_name` 必填，去除首尾空白后最多 50 个字符，不允许控制字符。
- `mobile` 必填，使用 11 位中国大陆手机号样式；该明文只存在于本地命令计划，禁止写入业务用户文档或日志。
- `class_id` 必填，最多 128 个字符，只允许英文字母、数字、下划线和连字符，且必须属于调用方预先提供的允许班级集合。
- 任意字段去除前导空白后以 `=`、`+`、`-`、`@` 开头时，按电子表格公式注入拒绝。
- 文件内或既有账号集合中重复的学生编号、手机号均拒绝；文件内重复会标记全部相关行，不默认采用第一行。
- CSV 支持标准双引号、逗号和双引号转义；未闭合引号、引号后多余字符、列数不符均返回稳定错误。

解析结果只生成 `TeacherStudentImportCommandPlanRow[]`，每项保留原始物理行号。结构错误、编码错误、错误表头或超过行数上限时整份计划失败关闭；普通行错误只排除对应行，并可生成仅含行号、字段、错误码和安全文案的 UTF-8 错误结果 CSV。错误结果不得回显手机号、姓名或原始单元格内容。

## 2. 筛选导出

导出输入是服务端已经授权的 `TeacherStudentListItem[]`，纯逻辑再次按班级、关键词和 `all/normal/attention/disabled` 状态筛选。固定导出列为：

```text
student_number,display_name,class_id,class_name,account_status,assigned_count,completed_count,overdue_count,redo_count,completion_rate,average_score
```

导出使用带 BOM 的 UTF-8 CSV，最多 100,000 行。所有单元格使用双引号转义；任何可能被电子表格解释为公式的值在内容前增加单引号。导出不包含手机号、家长关系、教师备注或其他敏感字段。

## 3. 后续独立流程

当前命令计划不能直接执行。后续若接入真实批量导入，必须另行实现并验收：

1. 使用可信教师 actor 重新校验 `student.manage`、目标班级实时授权和现有账号重复状态。
2. 通过受保护的服务端流程创建 CloudBase Auth 账号；手机号和初始密码不得进入业务数据库、审计正文或普通日志。
3. 账号创建成功后，以明确的幂等键、事务/补偿状态机写入业务用户、角色、班级 membership 和安全审计。
4. 对成功行和错误行给出可追溯结果；不得把“已生成本地计划”报告成“账号已创建”或“数据已导入”。
5. 任何云端账号创建、虚构种子导入、规则发布或部署仍需对应人工门禁与独立授权。

本地实现位于 `workspace/m1-cloudbase/src/teacher-students/bulk-csv.ts`，测试只使用虚构学校、班级、姓名、学号和手机号样式数据。
