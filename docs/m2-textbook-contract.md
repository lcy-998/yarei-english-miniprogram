# M2 教师教材中心契约（本地施工）

> 范围：T-11、T-12、T-13、T-14、T-16。以 `product-requirements-core.md` 和 `page-interaction-spec.md` 为准。本文件记录本地实现和未验收边界。

## 授权与资源

- `teacher-textbook-query` 只接受可信教师会话。班级列表需同时满足当前 `content.read` 权限、教师班级授权和会话 `scopeIds`；保存/发布另外要求 `task.publish` 与当前班级授权。
- 同步学课本从已上架 `learning_resources` 中的 `reading.category=synchronized` 获取；目录必须有年级、学期、教材版本、内容版本及章节结构。`payload.textbookChapters[].lessons[]` 可提供明确课次；缺少课次时只展示已有章节，不猜测页图就是一节课。班级、年级和资源可见范围都在服务端复核。
- 教材中心只显示授权结果。内存回退模式没有可确认的同步课本，因此 T-14 使用明确空状态，不能保存虚构班级配置。真实教材、版权与正式导入仍属于后续接入门禁。

## 班级教材配置

- `class_textbook_configs` 以组织和班级生成稳定 ID。草稿 `textbooks` 保留课本、章节与课次排序和内容版本；`publishedTextbooks` 单独保留上次发布快照。修改草稿不改动已发布安排或历史课堂任务。
- `teacher-textbook-command` 的 `saveClassTextbooks`/`publishClassTextbooks` 要求 `operationId` 与预期版本。事务中复核每本课本的当前版本、上架状态、班级可见性、年级及完整章节/课次 ID 集合，再写配置及幂等回执；失败保留客户端输入。
- T-13 仅调整课本、章节和课次顺序，不改教材正文。发布时提示原任务仍使用发布快照。若课本失效，页面保留条目并阻止保存/发布，教师可移除后重试。

## A-05 管理员配置

- `textbook-admin-query/command` 只接受独立管理后台的管理员会话，且要求组织级 `organization.manage` 授权。请求不接受客户端提供的操作者或组织身份。成功写入同时保存幂等回执与操作日志。
- 教材中心设置分别保存 `draft` 和 `published`：班级教材/同步学教材模块启用状态、可见班级及班级大盘字段。教师 T-11/T-12/T-14 只读取已发布设置；无配置时采用现有授权班级的默认布局。
- 同步课本可见范围先保存在 `textbook_catalog_drafts`，不会立即更改教师可见性；管理员发布时复核资源的授权演示/版权状态、页图目录和目标班级年级，再原子更新 `learning_resources` 的上架状态与可见范围。停用只阻止新引用，历史任务快照保留。
- A-05 页面提供班级与目录筛选、教师视角元数据/章节预览、范围草稿、发布和二次确认停用。本地无云环境使用独立内存预览，页面明确提示未写入云端；无教材数据时呈现空状态，不生成未经授权的正文或页图。

## 任务引用

- T-14 配置班级教材时可一次选择多本课本；从课本库布置任务时一次选择一本，确认前读取全部稳定页 ID、复核授权及内容版本，再带回 T-06。需要多本内容时可返回任务选择器继续添加。T-13 的课本卡片“布置任务”采用相同整本页 ID 规则；最终由 T-06/TaskCore 再次验证并冻结。
- T-16 阅读目录由原有条件分页接口提供，按五个阅读分类筛选；进入详情读取章节和稳定页 ID。整本、章节和指定页范围均传明确 `pageIds`，通过 session 的 `setTeacherReadingSelection` 回传 T-06，避免目录默认页数被误当成整本页数。T-06/TaskCore 需将该页集合写入任务规则和发布快照，并由服务端复核。
- 听力、视频和任务配音发布仍按 M3 边界关闭；教材中心音视频材料入口目前提示 M3 开放。

## 验证与限制

- 本地测试应覆盖跨班/跨组织拒绝、资源下架与版本变更、章节顺序、草稿与发布快照隔离、幂等重试、回执失败回滚和严格请求字段。
- 云函数已部署到非生产环境，A-05 管理员总览和虚构教材草稿预览通过只读验证；微信开发者工具页面操作、真机、真实资源导入以及大目录性能未验证。教师同步课本目录使用 `_id` 稳定分页、每批最多 50 条与每次最多 10 批的有界扫描，查找条件多且匹配稀少时可能需要继续加载。大规模目录上线前仍须按组织、类别、状态、年级和版本核对索引并测量性能。管理员目录总览仍为受限读取，内容规模扩大前须增加分页。
