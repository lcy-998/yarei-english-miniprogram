# M2 基础统计口径（T-04 / G-04）

本文件记录 0.27.0 权威需求下的实现，不扩大 `DATA-001` 的 P1 报表范围。非生产云端教师基础统计只读入口已通过；报表明细/导出、微信开发者工具页面及真机仍未完整验收。

## 统计窗口与来源

- 时间筛选默认近 7 天，支持近 30 天与自定义日期；自定义范围最长 366 天。日期按学校时区解释，区间包含首尾日期。
- 任务卡片、趋势与明细以**任务截止日**筛选。接口返回 `periodBasis: taskDueDate`，避免把提交日与截止日混为一谈。
- 分母为筛选内已发布、未撤回且当前可见的学员任务关系数；分子为关系状态 `awaiting_review` 或 `completed` 的数量。无任务时完成率为 `null`，页面显示“未记录”。
- 逾期数为关系标记 `isLate` 或当前状态 `overdue` 的任务数，一条任务只计一次。
- “任务提交次数”统计上述任务关系下已保存且有 `submittedAt` 的提交版本，重交版本各计一次；草稿不计。
- “已记录平均成绩”只纳入最新已提交版本的教师最终分，或可从发布快照复算的客观题自动分；无有效分数时返回 `null`。明细使用相同分数来源。
- 自主配音提交数在 CloudBase 已接通作品事件时，统计筛选日期内服务端已封存并提交的作品；按作品提交日计数。内存回退无作品事件时返回 `null`。
- 学习时长、练习正确率、跟读记录目前没有贯穿 T-04/G-04 的完整可核对事件来源，服务返回 `null`，页面显示“未记录”。不得从任务标题、资源标识、进度百分比或演示内容推断。

## 授权与导出

- T-04 服务端逐次检查可信教师身份、`student.read`/`task.read` 角色权限、当前有效班级授权和会话班级范围。跨班筛选返回 `FORBIDDEN`，非授权学员返回 `NOT_FOUND`。列表与导出只出现当前授权范围中的学员任务关系，姓名使用脱敏展示字段。
- G-04 服务端逐次检查有效家长与孩子绑定关系；解绑后旧会话也不能读取孩子统计。家长只看已绑定孩子，不提供跨班或跨孩子比较。历史任务可以按孩子曾所属班级查看。
- T-04 的 `exportTeacherCsv` 在服务端用**同一过滤条件**重算统计后生成 UTF-8 CSV，仅包含可核对的任务明细字段，并对电子表格公式前缀做转义。当前小程序通过“导出 CSV”按钮复制 CSV 文本，用户可粘贴保存成文件；小程序本地文件分享尚未验收。G-04 导出默认关闭，待明确权限配置再开放。
- 报表不返回提交正文、作答原文、教师私密备注或家长联系方式。

## 接口与页面

- CloudBase 函数：`learning-stats-query`，动作为 `teacherReport`、`parentReport`、`exportTeacherCsv`。
- 教师入口：T-01 工作台、T-02 学员列表、T-03 学员详情 → T-04；家长入口：G-01 首页、底部“报告” → G-04。
- T-04/G-04 展示加载、空数据、网络/授权错误与重试；筛选及明细均从服务返回的数据形成。

## 待联调与限制

- 尚未在非生产 CloudBase 部署或验证统计函数，尚未在微信开发者工具与真机检查视觉、返回保留筛选和 CSV 分享体验。
- 当前任务数据使用全组织读取再按授权范围收窄；M2 云端容量与响应时间需另行验证。`DATA-001` 的跨能力全量报表、大规模异步导出不在本切片内。
