# M2 任务模板本地实现记录

> 2026-09-26；仅虚构数据和本地验证，尚未云端部署或完成微信开发者工具验收。

## 范围

- T-10 仅向教师展示当前组织且内容处于其授权范围内的系统模板，以及本人个人模板。系统模板只读；个人模板可保存、编辑、复制、重命名和软删除。
- 模板保存名称、描述、内容项及完成和计分规则，不保存发布对象、具体开始/截止时间、教师备注或学生提交。保存时固化内容及规则快照，并在使用时重新核验资源是否上架、当前教师是否有共同授权班级。
- T-10 使用模板调用 `task-command.instantiateTemplate`，由服务端从已保存的冻结内容创建无对象、无时间的独立课堂任务草稿，并在同一事务中把模板使用次数增加 1。T-06 打开该草稿后要求重新选择对象和时间；未改变的内容沿用模板原快照，发布前重新核验当前资源上架与目标班级授权。模板或资源后续修改不会改变该草稿及其发布快照。
- 模板操作采用可信教师会话、预期版本与操作标识；重试复用回执，版本冲突拒绝覆盖。学生没有模板入口，也不能调用模板接口。

## 本地验证与剩余事项

- 模板服务覆盖冻结、可见性、个人操作、系统模板只读、并发版本、回执回滚及共同授权班级；页面入口覆盖使用模板时传递实际模板 ID。
- 非生产 CloudBase 中已验证系统虚构模板读取、实例化、幂等使用次数、冻结习题项及补齐任务后发布回收；T-10→T-06 页面实际操作和资源换版后的云端独立快照仍待验收。
- 使用次数在服务端成功创建独立草稿时计入；教师随后放弃草稿仍计一次使用，不把单独的只读模板预览计为使用。若产品希望只统计最终发布次数，需要另定统计口径并调整服务调用时点。
