# M2 学校习题目录接口与数据包（开发中）

> 依据：`product-requirements-core.md` 0.27.0 的 TCH-004/TCH-019 与 `page-interaction-spec.md` 的 T-15/T-18。虚构内容与函数已在非生产云端部署，题目目录按目标班级查询及授权拒绝通过；大目录性能和页面人工验收仍待完成。

## 目录读取

- `content-query.listSchoolQuestions` 接收 `filters` 与 `{ limit, offset }`。筛选字段为年级、教材版本、单元、知识点、题型、难度、关键词，以及可选目标班级。单页 1—50 条、偏移 0—10000；返回题目摘要和 `nextOffset`，不返回答案或解析。
- `content-query.getSchoolQuestion` 接收题目 ID 与可选目标班级，供授权教师预览题干、选项、答案和解析。客户端不传教师、组织或会话身份字段；云函数从可信会话重新判定角色、当前班级授权与资源可见范围。
- `content-query.listSchoolQuestionFacets` 只返回当前教师可见题库中的年级、教材、单元、知识点、题型和难度组合，不返回题干或答案。T-15 据此生成逐级筛选项，切换上级条件时清除下级条件。
- 目录只列已上架、未删除、当前组织内且对目标班级可见的题目。教师被撤权后旧会话查询失败；详情和分页下一页均重新校验。目标班级含未授权班级时整体拒绝。
- 关键词在服务端对标题、题干及知识点进行匹配，页面只接收分页结果。当前实现每次最多扫描 10 个、每批 50 条的有序数据库页；后续大规模验收需以实际目录规模验证索引、查询延迟和搜索完整性，必要时建立独立搜索索引。
- 筛选元数据接口当前按 50 条一批读取并去重，最多覆盖 10000 条目录记录；超过界限会明确失败，不返回不完整的选项。大规模性能及增量更新策略仍须独立验证，不能把本地虚构数据通过视为云端目录容量验收。
- `content-query.listTaskCatalogResources` 为 T-18 的阅读与词包提供带目标班级授权的条件分页摘要，按类型、来源、年级、学期、教材、单元、难度和关键词查询；`getTaskCatalogResource` 供跨页选中项、旧任务编辑及返回布置表单时逐条复核。单页最多 50 条，不返回阅读页图正文或词条；每次查询及下一页都重新检查教师当前班级授权。新版 T-06 使用 `getDraftOptions.catalogMode=selector` 只获取授权班级，内容从选择器按 ID 回填；旧请求保留整批读取以兼容 M1。任务预览和发布已逐条复核所选资源，不再为这些动作整批扫描目录；大规模性能仍须用实际目录与云端环境验证。
- `content-query.listTaskCatalogFacets` 从当前教师与目标班级可见的阅读/词包目录生成来源、年级、学期、教材、单元和难度组合；T-18 按来源至难度的顺序收窄候选值，切换上级条件会清除下级条件，跨筛选已选项保留。缺少教材版本的资源使用内部值 `__unlabeled_textbook__` 筛选并显示“未标注教材”。目录筛选接口已接入来源与学期；元数据仍最多扫描 10000 条，超过界限明确失败，云端容量及索引尚未验证。
- 2026-10-02 页面空态修正：T-15/T-18 只有在当前筛选的后续页已查完时才显示“暂无匹配”；有 `nextOffset` 时提示继续查找。切换条件清除旧结果并防止旧请求回填，但保留已选项。此项只改善稀疏授权分页的页面状态，不改变 10000 条筛选元数据扫描上限或代替大目录性能验收。

## 虚构题目文档

M2 的 `learning_resources` 习题文档需同时满足查询与历史快照：

| 字段 | 要求 |
| --- | --- |
| `_id`、`organizationId`、`schemaVersion`、`version`、`deletedAt` | 文档主键、组织归属、版本和删除状态 |
| `type`、`status`、`contentVersion` | `exercise`、`published`、正整数内容版本；下架不可新引用 |
| `visibility`、`copyrightStatus` | 组织或授权班级范围；开发种子只用 `demo` |
| `title`、`grade`、`textbook`、`unit`、`knowledgePoint`、`questionType`、`difficulty` | 顶层目录索引字段；缺少可选项时页面如实显示未标注 |
| `stem`、`options`、`correctAnswer`、`explanation` | 教师预览数据；学生端作答须从已发布任务快照读取其可见部分 |
| `payload` | 含 `questionIds`、`questionType`、题干、选项、答案和解析；与顶层题目字段一致，用于任务发布快照；缺失或不一致时不进入可引用目录 |

`contentVersion` 在 CloudBase 任务快照中使用数字。题目正文由后台管理员负责导入、纠错替换和上架；教师端仅浏览、预览和引用。变更内容应生成新版本，已发布任务保持原快照。

## 单题作答证据（本地已接入）

- 发布时校验一个题目资源对应一个稳定 `questionId`、合法题型、题目内容和完成规则，并把完整题目写入任务快照。旧演示资源没有 `questionIds` 时继续使用原计数口径，不能伪造逐题证据。
- 学生任务查询从发布快照只返回题干、题型和选项，不返回标准答案或解析。学生提交 `{ kind: 'exercise', answeredQuestionCount: 1, questionResponses: [{ questionId, response }] }`；服务端拒绝伪造的对错、外部题目 ID、缺失或不属于选项的答案。
- 正式提交由服务端对发布快照判定客观题，保存学生原始回答、题目 ID、判定与正确题数。教师查询当前提交时，按同一快照返回题干、学生答案、正确答案、解析和判定；旧提交缺少逐题记录时明确显示“未记录”。主观题保留待教师评分。
- 同一任务可包含多道独立题目项。已提交的结构化客观题按发布快照重新计算系统分数；默认等权，教师提供权重时发布前要求合计 100%。学生、教师完成情况和已绑定家长的当前任务视图均可读取该系统分数。教师发布正式评分时若覆盖系统分，必须填写原因，反馈保留原分和原因，教师只读详情可复核。
- 当前自动总分仅对包含 M2 结构化习题且全部计分项可自动评分的任务生成；旧 M1 计数式演示任务继续使用人工评分。主观题、录音等仍需教师评分。虚构题目的 memory 回退已覆盖单题发布、草稿、逐题提交、自动分、教师复核和家长只读；混合阅读/词包/客观题的演示提交可核对已保存学习进度并等权汇总。内存学习进度仍按资源保存，不能代替逐任务阅读范围及首次拼写证据；完整跨类型权重、历史提交版本切换及家长逐题详情仍待完成，不能报告为课堂习题闭环通过。
