# M2 学生自主学习目录（本地施工）

依据：`product-requirements-core.md` 0.27.0 的自主词包/阅读目录规则与 `page-interaction-spec.md` S-02、S-03。仅使用虚构内容；接口已部署到非生产 CloudBase，阅读指定页与单词任务的服务端闭环通过，目录页面和真机仍未验收。

## 接口与权限

- `content-query.listStudentCatalog` 接收 `filters` 和 `{ limit, offset }`，单页最多 50 条，返回已授权内容的目录摘要、匹配总数与下一页偏移。`listStudentCatalogFacets` 返回当前学生可见词包的年级、教材、单元组合，或阅读当前分类下的年级、难度、主题组合；两者都不返回词条、答案、阅读页图。
- 请求不得携带学生身份、组织或班级；云函数从可信会话确认学生角色、`content.read` 权限与当前有效班级关系。每次搜索、翻页和筛选元数据读取都重新检查权限。目录只列本组织、已上架、未删除且对该学生班级可见的内容；仅供任务使用的旧阅读资源不进入自主目录。
- 选择词包后调用 `getVocabularyPack(id)`，打开阅读调用 `getReadingResource(id)`；详情接口再次检查权限及上架状态。从 S-09 进入单词任务时使用已发布任务快照，不能切换为自主目录中的其他词包。学生最近选择记录和练习进度以学生 ID、词包 ID 隔离。
- 目录支持关键词、年级、教材、单元或固定五类阅读分类，以及年级、难度、主题条件。缺教材标识保留为空值，并由页面显示“未标注教材”，筛选内部值为 `__unlabeled_textbook__`；不从标题或 ID 推断教材。阅读主题仅来自资源 `theme` 元数据，缺失时不伪造筛选项。

## 当前限制与验收门

- 为精确返回匹配总数及动态筛选项，服务端目前最多按 50 条一批扫描 10000 条候选记录并在超限时明确失败。数据库适配器仍解码资源文档后投影摘要；大规模性能、索引和正文投影需要在非生产云端以真实规模验证。已加载阅读卡片逐本查询学习进度，但不读取书籍详情；后续可合并为授权批量进度接口以降低调用量。
- 自主阅读收藏仍沿用 M1 的按 ID 详情/进度写入逻辑。筛选或目录请求失败时保留当前条件，可重试；M0 内存回退仍只含虚构演示数据。
- 本地专项验证覆盖学生权限、跨班内容隔离、下架与任务专用资源过滤、分页摘要、未标注教材、动态筛选、伪造字段拒绝和客户端会话传输。CloudBase 部署、云端容量、微信开发者工具、真机与弱网验收仍需独立执行。
