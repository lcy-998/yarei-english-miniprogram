# 雅睿英语全项目视觉设计交付方案

> 目标：按产品里程碑分批完成视觉系统、公共组件、生产素材和页面主稿，并经过对应批次审批后再实现页面样式。

> 2026-10-01 补记：0.38.0 产品基线将 A-01—A-08 的后续实现改为 M3 原生小程序页面。本文既有后台桌面主稿与 G2/G3 交付记录仅代表 M1/M2 网页后台历史设计；原生管理页重新以 390×844 为主画板，批准状态另按 `docs/visual-page-register.md` 的迁移说明管理。

## 1. 基本原则

- 功能、字段、权限、状态和里程碑以权威产品文档为准，视觉设计不得增删功能。
- 页面先设计、审批并冻结，再实现；未批准页面不得进入正式 WXML/Less 开发。
- 每个页面编号只能有一张当前有效的页面级效果图。
- 页面级效果图固定表现“正常有数据”的主状态；加载、空数据、错误、无权限、下架等放入独立状态板。
- 小程序页面（含 M3 原生管理工作区）的唯一新主画板为 390×844；M1/M2 网页后台历史主画板为 1440×900。横屏和平板是响应式补充稿，不替代对应主稿。
- 视觉设计可以跨里程碑规划，但页面开发仍严格执行 M0 → M1 → M2 → M3 → M4。

## 3. 审批门

### G0：视觉 DNA 与跨角色母版

先提交以下 5 张关键页面，由用户逐张确认：

- P-01 登录页：品牌、表单和公共背景。
- S-01 学生首页：学生端信息密度、吉祥物和底部导航。
- G-01 家长首页：亲和感与数据概览平衡。
- T-01 教师工作台：高信息密度下的品牌延续。
- A-01 后台工作台：桌面端表格和卡片语言。

退出条件：五张母版均标记为“已批准”，颜色、字号、圆角、图标、背景、导航和吉祥物规则冻结。

### G1：M0 核心闭环页面

完成 M0 的 14 个页面主稿：P-01、P-02、T-01、T-05、T-06、T-07、T-17、T-08、S-01、S-08、S-09、G-01、G-03、G-05。

退出条件：所有主稿唯一、无死链歧义；任务数字、角色和状态前后一致；用户批准关键页面 P-02、T-06、S-09、T-17、G-05。

### G2：基础组件与 M1 增量页面

完成 P-03、P-04、S-02、S-03、S-04、G-02、T-02、T-03、A-01、A-02、A-03、A-04，并冻结表单、列表、筛选、组织树和以大幅绘本/教材页图为主体的基础阅读组件。

退出条件：用户批准 S-04、A-02、A-03；组件状态板覆盖默认、按下、禁用、加载、错误。

### G3：教学扩展页面

完成 M2 相关的自然拼读、配音、班级、排行榜、模板、教材、题库、统计和长期任务页面。

退出条件：用户批准 S-07、S-11、T-09、T-13、T-15；页面与组件不引入新的视觉语言。

### G4：媒体、AI 与复杂状态

完成 S-05、T-19、T-20、A-08 等媒体/AI 页面，以及播放器、录音、评分、审核、映射和防快进状态板。

退出条件：用户批准 S-05、T-20、A-08；异常状态保留用户内容并有清楚恢复路径。

### G5：响应式与最终交付

补齐规范要求的横屏、平板、200% 字体、长文本、键盘、弱网和并发冲突补充稿。

退出条件：50 个页面均有唯一 `current` 主稿；必要响应式稿和状态板齐全；资产清单、组件映射和视觉 QA 清单完整。

## 4. 页面效果图规则

- 文件名固定使用页面编号，例如 `S-01.png`，不使用“最终版2”“新版”等名称。
- 主稿只展示一个完整页面，不使用三机拼图、手机外框或透视展示。
- 页面文字必须来自交互规格和统一演示数据；禁止 AI 生成伪文字。
- 页面主稿不承担所有边界状态；状态差异通过组件状态板和状态附图说明。
- 每次修改必须记录原因、影响组件和审批结论。
- 只有用户明确回复“通过”或“采用”后，页面状态才能从“待审批”变为“已批准”。

## 5. 组件交付范围

基础组件至少包括：

- 微信安全区、导航栏、底部 Tab Bar、后台侧栏和账号区；
- 主次按钮、文字按钮、图标按钮、输入框、选择器和日期控件；
- 今日任务卡、内容卡、统计卡、入口卡、列表项和表格；
- 状态标签、进度条、步骤条、角标、未读标识；
- 筛选、搜索、分页、全选、已选摘要；
- 弹窗、抽屉、Toast、二次确认、未保存离开提示；
- 音频/视频播放器、倍速、磨耳朵、不可快进；
- 录音、波形、上传、AI 生成、评分维度和错误恢复；
- 加载骨架、空状态、网络错误、无权限、下架和停用状态。

每个组件必须有尺寸、间距、文字、颜色、默认/按下/禁用/处理中/成功/失败状态以及对应页面清单。

## 6. 素材生产规则

- 品牌 Logo、官方吉祥物和已有授权素材优先直接复用，不由 ImageGen 重绘身份。
- 新插画使用已批准页面作为风格参考，并保持同一色板、光影、边缘和材质。
- 可复用素材必须单独导出透明 PNG/WebP；图标使用 SVG 或代码实现。
- 图片中不得烘焙业务文字、按钮、进度、分数或状态。
- 每项素材记录来源、用途、授权、原始尺寸、生产尺寸、透明通道、压缩结果和引用页面。
- 内容型插画与品牌背景分离；更换教材或任务内容时不得改动页面结构。

## 7. 评审输出格式

每次评审只提交一个批次，包含：

1. 本批页面缩略索引；
2. 每页唯一主稿；
3. 与上次相比的变化；
4. 新增或调整的公共组件；
5. 需要用户确认的明确问题；
6. 页面台账和审批状态。

未通过的页面只做定向修改，不同时改变色彩、布局、插画和文案四个维度。

## 8. 正式开发准入条件

页面样式开发按产品里程碑分批准入，不要求在 M0 开始前完成全部 50 页审批。

### M0 页面样式准入

M0 页面可进入正式 WXML/Less 实现的条件：

- G0 与 G1 已批准；
- P-01、P-02、S-01、S-08、S-09、G-01、G-03、G-05、T-01、T-05、T-06、T-07、T-08、T-17 均在页面台账中标记为“已批准”；
- M0 所需导航、按钮、输入框、任务卡、列表项、状态标签、点评卡和通用状态板已批准；
- M0 生产素材已拆分、命名、压缩并登记；
- M0 页面—组件—素材映射完整；
- M0 竖屏视觉 QA 无阻断问题。

满足上述条件后，只能实现已批准的 M0 页面；视觉实现必须先沉淀公共组件，再应用到页面。未批准的 M1—M4 页面不得提前固化样式。

### 后续里程碑准入

- M1 页面依赖 G2 批次批准及对应组件状态板。
- M2 页面依赖 G3 批次批准及对应教学扩展组件。
- M3 页面依赖 G4 批次批准及媒体、AI、异常恢复状态板。
- M4 前完成 G5 响应式补充稿、全部 50 页主稿、资产清单、页面映射和最终视觉 QA。

业务领域层、service/repository 合约和与视觉无关的技术准备可继续按里程碑推进，但不得提前固化未批准页面样式。
