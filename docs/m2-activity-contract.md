# M2 打卡活动服务契约（开发中）

> 产品规则以 `product-requirements-core.md` 0.29.0 与 `page-interaction-spec.md` 的 T-09/S-11 为准。本文件记录本地施工和剩余验证，不代表活动功能已交付。

## 已接入的本地服务

- `ActivityService.saveDraft` 保存名称、说明、单班日期范围、休息日及 M2 允许的阅读、单词数量、练习分数、提交作品条件。学校时区由服务端组织资料给出，客户端不能指定。无效日期、重复休息日、重复条件和越界分数会被拒绝。
- `ActivityService.publish` 在同一写事务中再次确认教师当前班级授权、活动版本和有效学员关系，固化参与学员 ID 与脱敏昵称；草稿不向学生开放。任务开始后转班或账号资料变化不得改写已发布对象快照。
- 发布时在同一活动快照中为每个非休息日生成一个 `dailyInstances[]` 日期实例（稳定 ID 为活动 ID + 学校日期，记录班级、发布版本和生成时间）。实例引用同一份发布对象与条件快照，不为 500 名学员重复创建每日行；休息日没有实例。发布后新增未来休息日时，仅从活动快照移除该未来日期实例，并追加版本化变更记录；已经生效的实例、学生完成证据和补记记录不改写。完整发布快照采用应用内部 1,000,000 UTF-8 字节预算：服务端先估算日期实例体积，再校验实际序列化体积，超出返回 `VALIDATION_ERROR` 并保留草稿。此预算不是已证实的 CloudBase 单文档上限，须在非生产环境实测。
- 发布事务逐项读取每日条件引用的资源，确认仍已上架、类型匹配且对活动班级可见；同时冻结资源内容版本、阅读页 ID 集合、词包词条 ID 集合或题目 ID。缺失、下架、跨班级、类型不符或缺少必需快照时返回资源不可用，并保留原草稿。已发布活动不因原资源后续改版而改变条件。作品条件只有在对应的已授权作品资源可核验时才能发布，不以任意资源 ID 绕过。
- 写操作使用 `operationId` 与预期版本；同一请求重试返回原结果，复用操作标识但修改内容会冲突，并发重试只保存一份。失败写入回滚，不留下部分发布记录。
- 教师读取按当前授权班级过滤；学生仅能读取本人在发布快照中的活动。现有 `activity-rules.ts` 负责休息日日历、四类条件、学校自然日、补记和并列排名的纯计算。
- `DocumentActivityRepository` 已将上述读写映射到 `checkin_activities` 与 `checkin_activity_operations`，并在同一文档事务中读取组织、班级、授权及有效学员。记录按组织、文档版本和软删除状态读取；写入采用创建或预期版本替换，回执 ID 由操作范围生成。返回学生前只投影允许的活动、条件和脱敏学员字段。已在非生产 CloudBase 完成 36 人虚构活动发布、休息日、学生日历和进行中榜单，以及 500 人活动发布和无提交证据的进行中榜单分项验证；结束锁榜与 500 人均有每日证据时的峰值性能仍未云端验收，详见 `docs/reviews/m2-nonproduction-execution-2026-09-27.md`。
- `activity-command` 的 `saveDraft/publish/addFutureRestDay` 与 `activity-query` 的 `listForTeacher/getForStudent` 已接可信业务会话函数入口。写请求严格校验操作标识、预期版本、日期和四类开放条件；查询拒绝写字段，身份、组织及学校时区只能由服务端获得。小程序 service 已映射这些动作；内存模式明确返回“服务不可用”，不生成虚构打卡结果。两项函数已加入本地离线构建清单及不含凭据的部署模板。
- T-09 本地页面已从 T-05 布置方式入口进入，读取教师活动列表，支持选择班级、日期/快捷周期、按星期多选休息日、T-18 内容和单词/练习阈值，保存与编辑草稿、二次确认发布。页面将选中的星期限定在日期范围内并展开为具体 `restDates[]`，继续使用既有服务快照格式；旧草稿非周期逐日日期在教师主动选择星期前保持原样。失败保留表单和操作标识；没有可信每日证据时完成率与榜单显示“未记录/待接入”。
- 旧资源级单词汇总不能反推某日完成或首次拼写；阅读原有最新进度也不能证明指定范围。`learning-progress-command.saveReadingProgress` 在同一事务中追加经资源页校验的逐页访问记录，包含学生、资源、内容版本、页、进度版本和时间，重复请求不多记，失败回滚。`readingEvidenceFromPageEvents` 只在活动冻结版本的所有指定页于同一个学校自然日留有记录时生成阅读完成证据；缺页、跨日、其他学生、旧/新资源版本或未带版本的历史访问均不计。
- `exerciseEvidenceFromSubmission` 已从当前正式提交版本、发布时题目快照和实际原答重新判定单题分数；活动查询经学生本人和班级关系读取当前提交及教师反馈，核对活动冻结的资源版本、学校自然日和最低分。退回重做、旧版本、跨班级或缺失证据不计，教师对单题任务的正式改分仍归属原提交日期以支持跨日回补。
- `activity-query.getMyDay` 已按当前学生身份与活动发布对象读取指定学校自然日。阅读条件对发布后的版本化页事件与冻结页集合核验；练习条件对当前任务提交和题目快照重新判分。单词条件从逐词可信记录按冻结词包版本、发布后时间和学校自然日统计不同词的首次拼写，重复练习不增加数量，首次拼错仍计作完成一个词。作品条件只读取服务端核验并封存的本人配音作品，核对冻结素材版本、发布后提交时间、学校自然日及私有文件摘要；草稿和未核验文件不计。四类条件都有本地可信证据来源，休息日单独标识。
- 教师补记和撤销使用独立的追加记录，保存活动/学员/业务日期、操作人、原因、时间与版本；同一操作号幂等，版本不符冲突，回执失败事务回滚。教师仅能操作当前授权班级的已发布对象、非休息日且不晚于学校当天的日期；活动结束次日起拒绝新变更。学生日状态只展示是否补记，不暴露教师原因；撤销后立即按原始学习证据重新计算。T-09 已有按脱敏学员、日期、当前版本和原因执行补记/撤销的本地界面。
- `activity-query.getLeaderboard` 对当前班级学员和授权教师计算活动有效日，按阅读逐页、单词首次拼写、练习当前提交、本人封存作品证据及最新补记版本重算并列排名；学生还须有当前有效班级关系，转班后不能读取旧班榜单。活动结束后只读取 `checkin_final_boards` 中的最终快照：服务端维护方法 `finalizeActivity` 可在学校当地结束次日 00:00—00:05 创建一次不可变名次与逐人有效日期；缺少快照时不重新用可能已变化的源数据出榜。S-10/S-11/T-09 本地入口已接活动列表、活动切换、刷新、脱敏名次与本人固定区；撤权时清除旧榜单显示。
- 定时维护先按活动文档顶层 `endsOn` 查询学校当地昨日结束的活动，再推进普通活动/任务分页游标；优先队列每次最多四页、每页 25 条，按组织与结束日期保存游标，每处理一个活动才推进版本，超时重进可以从未完成的活动继续。这样大量不相关活动不会挤过 00:00—00:05 的锁榜窗口。已锁榜重复扫描幂等；错过窗口或锁榜失败只记录待恢复项，绝不以晚到且可能变化的证据重算历史榜单。旧活动缺少顶层 `endsOn` 时仍走普通扫描，可能进入待恢复项。
- S-11 本人名次可展开个人打卡历史，以服务端学校时区的当前日期为边界，按七个日期一批读取 `getMyDay`；休息日、完成、教师补记和证据不可用分别标示。失败保留已加载记录，授权失效清空个人结果。该页面仍未在开发者工具或真机验收。
- T-09 新建表单默认从次日开始、连续七天；教师可调整开始/结束日期并多选每周休息星期，星期选择随日期范围重新计算具体日期。客户端默认值仅供填写，发布时仍由服务端按学校时区校验具体日期快照。

## 尚未接入

- 阅读、单词、单题练习和封存作品的单日证据查询、教师补记/撤销、进行中榜单及最终榜单存储/读取已接入本地服务；定时维护触发已有本地可信事件和分页/幂等/错过窗口测试，500 人本地替身锁榜测试通过，500 人无提交证据的云端进行中榜单也已通过。定时函数曾短时挂接触发器并实际运行，随后移除；36 人最终榜单以显式测试时钟在真实云数据库完成一次锁定和重复幂等验证。但跨日评分回补全场景、真实 00:00—00:05 自动锁榜与 500 人均有证据时的峰值性能仍未验收。错过窗口的待恢复项尚无人工核查/补建最终榜单流程，不应标记为自动恢复。作品来源虽有本地服务与页面，真实素材、受控上传规则和云端文件核验尚未验收，不能将本地测试视为作品打卡上线。学生不得自行提交可决定打卡结果的汇总数或模拟 AI 分。
- 已发布活动可由当前授权教师以 `addFutureRestDay` 为学校当地尚未开始的活动日期新增休息日，必须提供 1—300 字原因和当前活动版本。服务端拒绝当天及过去、越界、重复、已关闭、已锁榜、撤权和并发旧版本请求；写入同一事务中更新日期集合、移除对应未来实例、追加操作者/时间/原因/版本审计，并以操作号幂等。T-09 可提交并查看此类变更历史；学生查询仅得到调整后的休息日，不返回教师原因和操作者。过去日期完成证据和排行榜已完成天数保持原样，有效任务日总数随新休息日减少。旧活动无审计字段按空记录兼容。
- T-09 当前必须手选开始日期，学校时区的“明天”默认值尚未接入；作品条件的资源模型已就绪，但没有已授权的预置视频可供页面选择。活动停用、家长只读详情、提醒通知、云端容量/恢复以及开发者工具和真机验收仍需继续实施。
