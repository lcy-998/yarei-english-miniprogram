# M3 开源跟读评分施工计划（2026-10-02）

> 状态：已确认技术方向、待可行性验证与 M3 施工准入。用户已同意以 Vosk 自托管方案提供**测试阶段的试验性跟读分数**，以合规儿童英语录音与人工评分的对照结果作为正式评分验收前提。本计划只覆盖 S-05 跟读评分及其任务证据接线；不替代 M3 教师 AI 点评、媒体审核、听力题对位或其他能力的方案。M2 当前仍为“开发中”，本文件不授权 M3 云端部署、真实儿童录音采集、付费开通或生产发布。

## 1. 目标与固定边界

1. 使用固定版本的 `vosk-model-small-en-us-0.15` 与 Vosk 开源运行库，不接外部 AI 评分供应商，也不在运行时从公网下载模型。模型约 40 MB，Apache 2.0；官方描述的小模型运行内存通常约 300 MB。模型与解码依赖的精确版本、来源、许可和 SHA-256 在本地试验通过后锁定。
2. S-05 保持既有产品契约：总分与发音、流利度、完整度三项均为 0—100；有效评分最多五次，任务取最后一次有效分；15 秒超时自动重试一次，失败保留录音，低置信度不返回伪分数。录制中的颜色、实时计时和结束时实际时长沿用现有录音交互规则。
3. 初期输出明确标注“试验性评分”。Vosk 是语音识别模型；单词识别与置信度只能作为发音清晰度的代理指标，不能宣称音素级发音诊断或儿童英语评分质量已获验证。试验结果不直接开放为打卡 AI 分条件或正式任务自动成绩；质量、性能和权限门槛通过后再按既有发布规则放开。
4. 只使用已核对的非生产环境和虚构账号。开发阶段使用原创/合成或明确许可的测试音频；真实儿童录音及其授权、保存与上传另行审阅。原始录音的 180 天保留/到期清理与历史成绩保留规则不因新评分功能改变。
5. 与现有 service/repository、任务发布快照和授权边界衔接；客户端传入的参考文本、学生 ID、文件 ID、分数与模型结果均不能直接成为可信评分依据。

## 2. 推荐架构

```text
S-05 微信原生页面
  → 现有私有录音暂存/封存流程
  → Node.js 跟读评分入口：可信会话、本人/任务项/版本/次数校验
  → 内部 Python 云函数：下载受控录音、MP3 解码为 16 kHz 单声道 PCM、Vosk 识别
  → Node.js 评分领域服务：文本对齐、质量门槛、版本化三维试验分与幂等记录
  → S-05 查询结果；教师按授权读取录音引用与原始评分
```

- **入口与权限**：在现有 Node.js 业务边界新增 `beginScore`、`getScore` 之类的明确动作。Node.js 从已发布任务/阅读内容快照取得参考文本，按当前学生本人、有效任务关系、录音归属、内容版本与提交轮次校验。非任务模式仍按本人授权阅读资源校验。Python 推理函数仅供可信服务端调用，客户端与匿名直接调用必须拒绝。
- **音频传递**：保留录音在私有云存储；Node.js 只向内部推理函数传递短期、限定目标的下载能力和预期 SHA-256，不把 20 MB 音频放进函数事件或日志。Python 下载后再次核对大小、哈希和音频格式。先验证 CloudBase 函数间调用与私有文件读取的实际权限形态，再冻结接口。
- **解码**：S-05 首选录制 MP3，与现有课堂录音路径一致。Python 试验包先用 MIT 许可的 `pyminiaudio` 将 MP3 转为 16 kHz、16 位、单声道 PCM，不依赖运行时下载或常驻容器。M2 的 `music-metadata` 只解析时长和编码，不能用于 PCM 推理。若实际真机产生 AAC，先记录失败并评审本地解码依赖；不得把合法录音静默判作发音差。
- **推理与计算**：Vosk 返回词、时间戳和识别置信度。服务端对参考文本做固定的大小写、标点及缩写归一化后按顺序对齐；完整度从覆盖比例，流利度从语速与停顿分布，试验性发音分从匹配词及置信度产生。归一化、阈值与权重都用 `algorithmVersion` 固定并通过对照样本校准，不把未经验证的识别置信度当成人工发音分。静音、噪声、严重截断或低置信度返回“暂无法可靠评分”，不占有效次数。
- **幂等与记录**：同一学生、录音哈希、参考文本快照、模型版本、算法版本及操作 ID 的重试复用同一评分尝试；不同录音或版本生成新尝试。保存评分状态、维度、总分、模型/算法版本、录音受控引用、质量原因、耗时和审计摘要；不得在应用日志中写录音原文、完整识别文本、临时地址或令牌。教师覆盖 AI 分仍须填写原因并保留原始分和提交版本。

## 4. 费用与性能停止条件

- 使用普通 Python 云函数，**不使用要求启用超限按量的 CloudBase 云托管/云托管函数**。CloudBase Python 普通云函数可用，但其适当内存、超时、构建包与平台计费必须在目标环境实测；现有项目记录为个人版，不能据此承诺环境本身免费。
- 初次部署前读取真实剩余配额并计算单次最坏资源消耗，设置仅供虚构测试账号调用的限量开关与调用数上限；每日核对函数执行量、存储和流量。预计会触及额度或平台提示购买/开启超限时停止，不自动升配或切云托管。
- 以客户端提交至结果可见的实际耗时测冷启动、热启动、短句、长句、弱网和重复请求；15 秒超时/自动重试一次按产品既定规则执行。普通函数无法在无额外费用条件下稳定满足时，保留录音与失败状态，停止正式发布判断并提交替代方案审阅。
- 失败回退只切回已留存的旧函数/客户端开关，评分尝试保留审计，不删除 M1/M2 数据或历史提交；不通过放宽授权、伪造分数或开启付费来掩盖失败。

## 5. 尚需后续冻结的决定

1. **正式质量数字门槛**：儿童朗读人工对照的样本量、人工评分一致性、相关性/误差与明显误判上限，须在正式质量验收前确定；本计划不自行把 Vosk 的识别测试集词错率等同于儿童发音评分准确率。
2. **儿童声音样本来源与授权**：目前只允许原创/合成虚构演示数据；公开语料或真实儿童录音的许可、隐私和使用范围须先审阅。无合规样本时只能完成技术验收，不能完成正式质量验收。
3. **M3 教师 AI 点评**：Vosk 只解决跟读试验评分，不能生成 T-08 的中文点评建议。该切片需另定开源/规则化方案及验收方式，不因本计划自动缩减 M3 范围。
4. **超出套餐后的路线**：若实际包体、冷启动、15 秒时限或调用消耗不满足零新增费用，保留本地适配器与数据合约，停止云端扩量，再由用户选择预算或新的技术方案。
