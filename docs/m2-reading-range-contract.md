# M2 阅读指定范围任务本地契约

> 2026-09-26；本地实现，尚未云端部署或完成微信开发者工具及真机验收。

- T-16 从当前授权且上架的阅读资源详情取稳定页 ID。整本、章节和指定页范围均把明确的 `pageIds` 与对应页数写进 T-06 的内容项；只有缺少页目录的旧任务继续按原页数规则兼容。
- 发布时 TaskCore 重新核对目标班级权限、资源版本及 `payload.chapters[].pages[].id`，将选中页集合连同内容和规则固化到任务快照；不存在、重复或数量不符的页阻止发布。
- 学生提交指定范围时，服务端只接受本人在任务发布后、当前快照内容版本中访问过的每一页。单纯填写页数或访问其他页不能完成任务。正式提交保存逐页 ID、页码和访问时间的只读证据；教师逐项检查按提交版本显示这些证据，旧提交缺失证据时明确标注“未记录”。
- 小程序学生任务页显示教师指定的页码，打开阅读时定位到范围首页；正式提交由服务端核验。页面尚未自动展示哪些指定页已访问，须在开发者工具与虚构阅读素材联调时检查引导是否足够清楚。
- 旧内存 repository 没有逐页可信事件，指定页任务的草稿与发布在该回退模式明确返回服务不可用，不显示虚构成功；普通旧阅读任务保持原兼容路径。
