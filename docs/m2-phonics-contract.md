# M2 自然拼读课程与练习（开发中）

> 依据 `product-requirements-core.md` 0.26.1 的 STU-002 和 `page-interaction-spec.md` S-06。本文只记录本地施工，不代表课程内容或页面已验收。

## 本地功能边界

- `PhonicsService` 仅向有效学生展示当前班级授权且已发布的课程。目录只返回课程摘要；详情包含音素、示例词、音频是否可用及不带答案的练习题。教师、其他学员和跨班级请求被拒绝。
- 每题作答只提交课程、练习轮次、题目、所选项及操作标识/版本；服务端从当前课程版本读取标准答案并保存原答、判定、轮次、次数和时间。同一操作重试复用原回执，过期版本或复用操作标识修改答案会冲突。
- 一轮练习在全部题目首次作答后生成该轮得分和完成时间；后续错题复习不改写该轮得分。完成后重新练习进入新轮次，历史成绩保留；上一轮未完成时服务端拒绝跳到新轮次。最近一次判定决定当前错题复习列表。提交失败保留学生选择，提交成功但后续进度读取失败时页面用可信回执保持反馈。
- 音素音频由服务端再次确认本人课程权限后签发短期播放地址，不在课程详情下发私有文件 ID。S-06 页面已接课程筛选、课程学习、发音播放入口、逐题作答、得分与错题复习；只从 P-04“学习工具”进入，不加入课堂任务。
- 内存及 CloudBase 文档事务适配器、严格云函数合约与本地独立构建包已接线；内存小程序模式明确返回服务未接入，不生成伪造正确率。

## 尚未验证

- 仓库没有已授权的拼读发音音频和完整课程内容；本地测试只使用虚构短元音课程。实际教材/发音内容须经来源与版权确认后导入，不把示例题当成正式课程。
- `phonics-query/phonics-command` 未经单项授权部署；微信开发者工具页面、音频播放、弱网及真机交互未验收。S-06 的进度和正确率尚未汇入 T-04/G-04 基础统计。
