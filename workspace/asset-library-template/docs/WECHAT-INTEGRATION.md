# 微信小程序接入规范

## 1. 总原则

资产流水线的最终消费者是雅睿英语微信小程序。资产库负责产生标准内容包，CloudBase/内容后台负责上传、审核、授权和发布，小程序负责播放、点读、跟读、作答和进度记录。

```text
本地源文件 → 资产加工 → 微信导入索引 → CloudBase 云存储/数据库 → 小程序
```

## 2. 存储分工

### 小程序代码包

只放：

- 页面代码和组件
- 轻量默认配置
- 必要的空状态/占位资源
- 不随教材增长的通用图标

不得放：

- 原始 PDF
- 整册教材页面
- WAV 制作母版
- 大量 MP3/AAC
- 教学视频
- 可动态更新的教材 JSON

### CloudBase 云存储或 HTTPS CDN

存放教材页面图、缩略图、MP3/AAC、MP4、字幕和需要下载的派生文件。文件键建议包含资源 ID、版本和哈希，上传后不得原地址覆盖。

### CloudBase 数据库

存放书籍、章节、页面、正文、词条、题目、点读映射、音频片段、资源版本、审核状态和可见范围。任务发布时保存不可变内容快照。

## 3. 微信导入索引

流水线生成 `exports/wechat/asset-index.json`。每一项包含：

- `resourceId`
- `version`
- `resourceType`
- `assetKey`
- `localManifestRelativePath`
- `deliveryStatus`
- `deliveryUrl`

首次生成时 `deliveryStatus=awaiting_cloud_upload`、`deliveryUrl=null`。上传工具完成云存储上传后回填 HTTPS 地址或 CloudBase fileID，再由后台执行审核和上架。

## 4. 小程序读取方式

- 页面不得直接拼接文件名或本机路径。
- 页面通过 service/repository 查询资源 ID 和版本。
- 教材阅读先加载 `thumbnails/` 中的 320px 轻量缩略图，再按页加载 `pages/` 中的 1600px 主图和点读映射。
- S-04 的可见阅读主体是绘本/教材页图，页图占据主要内容区域；OCR/结构化文本不在页图外另行渲染，只用于搜索、点读映射、跟读、无障碍和校验。
- 音频播放器读取统一媒体对象，支持五档倍速、磨耳朵、续播及任务模式连续进度。
- 听力题读取已经审核的 `startMs/endMs`；缺失或越界时禁止布置和提交。
- 三、四年级根据年级策略只展示音节字段，不展示 IPA。

## 5. 上线前检查

- 所有业务 URL/文件 ID 可在真机访问。
- 无本机绝对路径和 `file://` 地址。
- 页面图清晰且单页体积合理。
- 音频为 MP3/AAC，视频为 H.264/AAC MP4。
- 点读区域和音频时间轴经人工复核。
- 横竖屏切换后资源 ID、页码、播放位置和作答草稿不丢失。
- 内容下架不破坏历史任务快照。
