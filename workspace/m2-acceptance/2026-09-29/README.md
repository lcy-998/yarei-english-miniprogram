## 本地素材

- `assets/zoo-friends-cover.png`、`assets/zoo-elephant-page.png`、`assets/zoo-giraffe-page.png`：内置 imagegen 生成的原创虚构插图。小程序使用压缩后的 `miniprogram/assets/content/m2-zoo-*-v1.jpg`。
- `assets/phonics-short-a.mp3`、`assets/zoo-narration.mp3`、`assets/recording-example.mp3`：本机英语合成语音生成，示范内容均为本包自写句子。对应 WAV 是生成中间文件。
- `assets/zoo-friends-demo.mp4`：由两张原创插图和合成朗读制作的 10 秒虚构配音示范视频。
- `generate-audio.ps1` 和 `encode-media.ps1`：素材重建脚本。后者运行时需提供可用的 `ffmpeg` 路径。

云端上传路径限于 `m2-acceptance/2026-09-29/`，以及服务端为虚构作品生成的 `student-works/staging/` 与 `student-works/private/` 路径。存储权限保持原来的 `PRIVATE`；服务端签发的临时地址已通过读取验证。本次使用服务端受控上传建立已提交样例，**不能作为小程序客户端首次上传、录音权限、真机播放或弱网恢复的通过证据**。

## 执行与校验

在 `workspace/m1-cloudbase/` 执行 `node tools/run-m2-acceptance-setup.mjs inspect` 只读核对，`apply` 增量建立或恢复本包，`verify` 按学生与管理员权限读取。脚本只接受与本机私有配置和项目配置一致的环境，并要求 M2 基础虚构种子成功、目标组织/授权有效且目标班级恰有 36 名有效学员。相同 ID 已存在时复用，不轮换测试密码。

2026-09-29 实际 `verify` 通过：学生 3 项任务可读、36/1/1 份对象关系一致、习题答案未泄露；自然拼读音频、配音视频及已提交作品均取得临时播放地址；S-12 只显示已提交作品和有效草稿，不显示已删草稿；管理员 A-03 可见可恢复记录，A-05 可见数字年级班级及课本草稿。微信开发者工具页面操作、客户端上传、真机和弱网尚未用本包验收。
